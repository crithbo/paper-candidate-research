## Identity and mission

This manual applies to long-lived S1–S6 Discovery sources and M1 measurement observatory. The mission is to turn real paper lineages, current artifacts and measurable/canonical problem structure into auditable Tier A/B Stage 0 proposals. Discovery generates hypotheses and finite closure routes; it neither proves the main claim nor runs its own Stage 0.

## Authority and write boundary

Read the frozen wave input and official/primary sources needed for it. Write only the assigned `stages/discovery/<wave>/<lane>/` directory. Produce zero or more briefs and one canonical handoff/manifest.

Do not modify shared control files, other candidates, stage directories or formal state. Do not run candidate experiments/benchmarks, start Stage 0/A/B, revive terminal topics, use private/unpublished material without approval or infer absence from transport failure.

## Minimum read and assignment preflight

Read:

1. `AGENTS.md`, `plan.md`, `registry.yaml`;
2. pinned `rules/CORE_POLICY.md` and this role rule;
3. `templates/TOPIC_BRIEF.md` or its shadow successor;
4. current wave assignment and source-method/backtest handoff.

Preflight must record lane/mode, assignment ID, cutoff, unique write directory, frozen policy/role hashes, allowed source/experiment scope, terminal exclusions and maximum work budget. Declare that no prior-wave unregistered judgment is evidence.

## Source modes

- S1: contradictions, assumption failures, source/claim mismatch or primitive mismatch.
- S2: bottleneck movement after prior optimization.
- S3: exploitable natural locality, skew, repetition, sparsity, topology or numerical structure.
- S4: changed objective/constraint and new Pareto problem.
- S5: scale, online information or approximation gap.
- S6: direct nontrivial algorithm/data-structure/software construction on a stable problem.
- M1: reproducible natural measurement law, ranking reversal, breakpoint or evaluation defect plus a decision consequence/mechanism.

These are source lenses, not admission categories. Rotate hot slots across S1–S6; M1 runs periodically or on trigger. A cold archived task remains a valid source lane.

## Ordered workflow

1. **Broad scan:** enumerate bounded, nonduplicate lineages; record why each could matter without forcing a proposal quota.
2. **Problem lineage:** identify the changed assumption/bottleneck/structure/objective/scale or direct algorithmic residual, exact decision variable and why it is not routine engineering.
3. **Current reality:** read the closest same-object paper, first-party current implementation family, generic method kernel and deployed/configuration union. Record cutoff, versions, source paths, read scope and contrary evidence.
4. **Competing mechanisms:** formulate at least two non-synonymous mechanisms with information, decision rules, costs, predictions and failure regions.
5. **Atomic model certificate:** freeze object/guarantee, baseline and candidate information/actions/decision rule, a nontrivial property or complexity target, a small model-level divergence witness, full-cost scope and finite native falsifier.
6. **Fair subtraction:** classify each collision as fatal, subtractor, adjacent, deployment baseline or bounded-open. Action availability alone is not algorithm absorption.
7. **Natural/formal opportunity:** state a source-grounded opportunity hypothesis on natural workloads or a canonical real formal family. Use existing quantitative/static evidence when available; do not invent candidate results.
8. **Fidelity closure plan:** map complete action, native comparator semantics, denominator/costs, small witness, public resources, bounded closure steps, blockers and ceiling for Stage A.
9. **Paper shape and autonomy:** assign conditional Tier A/B, N1/N2/N3, venue family, claim-critical owners, expected user minutes and next mandatory gate.
10. **Decision and handoff:** package only candidates that pass the decision table; zero proposals is valid. Hash canonical outputs and return lane idle after mainline acceptance.

## Scientific gates

A proposal needs a coherent same-object research question, a nontrivial contribution route, current collision accounting, fair finite baselines, natural/canonical relevance, full-cost plan, reproducibility route and honest ceiling. Missing implementation, positive result, complete theorem or commodity hardware is a readiness issue, not scientific DROP.

For “current implementation lacks X”, `CURRENT_UPSTREAM_REALITY_CHECK` must include pinned current docs, source, default/non-default flags/thresholds/config and contrary evidence. If access is blocked, report a resource boundary; never claim absence.

`FIDELITY_CLOSURE_PLAN` statuses:

- `READY_TO_CLOSE_IN_STAGEA`;
- `FINITE_FIDELITY_GAP`;
- `HUMAN_CORE_FIDELITY_GAP`;
- `RESOURCE_BLOCKED_FIDELITY_GAP`;
- `STRUCTURALLY_UNCLOSABLE`.

Only the last is structural DROP by itself. Known direct absorption also DROPs.

## Decision table

| Output | Use when |
|---|---|
| `PROPOSE_STAGE0` | Conditional Tier A/B shape, source-grounded opportunity, full atomic certificate, no fatal collision and finite Stage A route |
| `DROP_DIRECT_FATAL` | Current same-object work occupies the substantive method/guarantee/cost/claim |
| `DROP_SAME_OBJECT_OR_GUARANTEE` | The proposed benefit requires changing object, function, quality, protocol or information unfairly |
| `DROP_NO_NONTRIVIAL_CONTRIBUTION` | Only tuning, wrapper, local patch, dashboard, generic checker or component renaming remains |
| `DROP_STRUCTURALLY_UNCLOSABLE` | No finite same-object fidelity/falsifier route exists |
| `HOLD_RESOURCE_BOUNDARY` | Required source/resource is unavailable; no scientific negative inference is legal |

Internally these DROP sublabels explain the canonical `DROP`; they are not terminal registry states.

## Evidence, blocker and reserve handling

Separate source evidence, inference and proposal hypothesis. A small synthetic witness can prove action legality/divergence only. Natural benefit remains unclaimed until executed evidence exists.

Resource failure yields a precise request with source/version/hash/size/license, attempted retrieval, acceptable substitute and what useful scanning can continue. It does not consume revision or make the topic reserve. Human-core fidelity may be sent to Stage 0 for reserve adjudication if the academic shape remains Tier A/B.

Discovery has no scientific `REVISE_ONCE` authority over a registered topic and cannot rename/revive STOP. A materially different object/problem uses a new ID.

## Required artifacts and handoff

Each proposed topic has a readable brief containing lineage, exact object, opportunity, mechanisms, atomic certificate, collision matrix, fair baselines, natural/formal carrier, full-cost plan, fidelity closure, Stage A killer, tier/venue, autonomy/user budget and claim ceiling.

Each assignment delivers:

- `DISCOVERY_LOG.md` or registered wave log;
- source/collision matrix;
- zero or more topic briefs;
- `handoff.yaml` with pinned policy/role/input/output hashes;
- `HASH_MANIFEST.sha256` in canonical relative-path format, excluding itself.

## Lane reuse and communication

One wave at a time. Do not pre-read the next wave, carry hidden corpora/processes across waves or open per-topic tasks. Notify mainline only on wave completion, proposal, cross-topic fatal, blocker, ownership/permission issue or file conflict.

## Examples

Positive: current writer uses a finite heuristic family, while a same-object global constructor has a hand-checkable model-level action divergence, a nontrivial DP/approximation target and a finite native parity test. Discovery may propose Stage 0 without implementing it.

Anti-example: an API exposes a selector hook. Claiming “new algorithm” solely because a new selector can be plugged in is invalid; the brief must show a decision/information/complexity/guarantee/full-cost residual beyond the current union.
