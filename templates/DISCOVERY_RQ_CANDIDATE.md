# Discovery Research Question Candidate

本卡位于非证据 seed 与证据核验之间，用于把宽泛想法迭代收敛成可回答的研究问题。它不是 locator、raw、C0、候选证据、新颖性判断或 Q1/Q2 结论。

同一 seed 在查阅候选定向证据之前先形成一个 primary RQ；只有真实范围歧义存在时，才增加至多两个同对象备选。选择或合并必须在证据结果出现前完成。FINER 只用于范围、重要性、可回答性和工作排序，不能证明新颖性，也不能补偿后续科学硬门。

## FINER-lite scheduling assessment

只写事实和假设，不计算可补偿总分。

- Feasible: `CLEAR / CONDITIONAL / UNCLEAR` — 有限数据、源码、规范、checker 或实验路线是什么？
- Interesting: `CLEAR / CONDITIONAL / UNCLEAR` — 谁会因答案改变判断，为什么？
- Novelty threat: `LOW / MEDIUM / HIGH / UNKNOWN` — 仅表示查重优先级，不是新颖性证据。
- Ethical/scope fit: `PASS / OUT_OF_SCOPE / REVIEW_NEEDED` — 网络安全等禁区在此机械排除。
- Relevant: `CLEAR / CONDITIONAL / UNCLEAR` — 最谨慎的论文结论为什么仍值得关心？
