# Submission Checklist

- [ ] Valid `formal_project_approval_id` and final user release decision recorded
- [ ] Authorship/contributions explicitly approved by user
- [ ] Venue and formatting requirements explicitly selected by user
- [ ] Every manuscript claim maps to evidence/limitation
- [ ] Citation and data integrity audit passes
- [ ] Reproducibility package and licenses are complete
- [ ] Negative/null results and exclusions are disclosed
- [ ] Full-cost, statistics and failure regions match the accepted claim
- [ ] Independent manuscript review and response are complete
- [ ] No private/unpublished material lacks ownership approval
- [ ] External communication/submission approval is explicit
- [ ] Final manuscript, supplement, artifact and manifest hashes are frozen

External submission remains prohibited until every user-only item is approved.
