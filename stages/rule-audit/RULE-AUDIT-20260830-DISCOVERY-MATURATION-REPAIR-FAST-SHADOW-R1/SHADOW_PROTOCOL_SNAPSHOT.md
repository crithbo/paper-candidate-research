# Bounded Debt Closure Shadow Protocol Snapshot

This is a non-production test protocol. It is not a live project rule and cannot alter canonical Discovery.

A nomination is eligible only when an exact anchor/version, stable object/guarantee, one primary RQ, typed endpoint/counterfactual, non-generic mechanism skeleton, finite carrier and falsifier exist; no known direct fatal exists; and exactly one bounded debt vector can be answered from at most two named primary sources without candidate execution.

Frozen before repair: object, RQ, contribution type, endpoint, guarantee, information contract, full-cost boundary and falsifier. Repair cannot change them, weaken baselines/denominator, substitute synthetic-only evidence, backfill a seed or run twice.

Outcomes: `BRIEF_READY / HONEST_ABSTENTION / SOURCE_OR_RESOURCE_BLOCKED / STRUCTURAL_INELIGIBLE`. A six-lane cycle freezes all nominations before selecting at most two by the precommitted order. Canonical output is frozen first and receives no effect.

The prospective test also records local executable carrier, decision endpoint, mechanism, paper artifact, group bridge, strategic alignment and resource realism as scheduling-only fields.
