# Pro review to project-rule mapping

| Pro requirement | Project implementation | Activation |
|---|---|---|
| Contribution-type contracts | New shared Discovery claim-pack protocol; brief and Stage 0 report record the type contract before Q1/Q2 mapping. | Shadow then production after calibration. |
| Rich claim package | Exact object, natural/canonical carrier, problem, atomic action, mechanism, information, comparator, effect target, output/guarantee, full cost, boundary, falsifier, dependencies. | Required in claim-pack mode. |
| Opportunity graph | Stable family ID plus typed relations: equivalent, contains, conditional specialization, alternate mechanism, complementary, prerequisite, competing explanation, independent. | Required in claim-pack mode. |
| Claim-level evidence audit | One compact Discovery evidence ledger containing query log, normalized versions and claim–source relations. | Required in claim-pack mode. |
| Operational stopping/reopening | Decision-ready facet checklist, heterogeneous independent search, contrary search, bounded-open outcomes and explicit triggers. | Required in claim-pack mode; terminal STOP remains non-revivable. |
| E1/E2 execution split | E1 static preflight; optional bounded E2 engineering smoke under an explicit resource contract. Neither determines academic status. | E1 in shadow; E2 only when assignment-authorized. |
| Direct-coverage fairness | Eight-predicate direct-coverage test; partial coverage becomes narrowing, not automatic elimination. | Hard gate in claim-pack mode. |
| Structural-negative discipline | Exhaustive structural DROP reasons plus explicit list of unfinished/resource/human-core non-reasons. | Hard gate in claim-pack mode. |
| Stage 0 feedback | Expanded repair codes and independent check of the contribution contract, coverage, evidence, current implementation and execution route. | Required in claim-pack shadow and production. |
| Evaluation controls | Paired same-snapshot historical regression, blind holdout, neutral rendering, style/adversarial perturbations, independent adjudication, prospective shadow. | Mandatory before production. |
| Metrics | Critical-source recall, false structural DROP, evidence completeness, audit time, stability, diversity, E1/E2, Stage0 repair and later claim survival. | Diagnostic; no proposal quota. |
| Parallelism | Keep six reusable lanes as ceiling; assign opportunity-family work with generation/audit/synthesis independence. Test 3 vs 6 separately. | No seat-count change in this patch. |

## Deliberate adaptations

1. The Pro review's multidimensional A/C/D/E states are Discovery-local audit coordinates, not a replacement for the authoritative project state machine.
2. E2 is not a mandatory pre-Stage0 gate because that would bias against high-value theory, scarce-hardware and human-core topics.
3. A fixed paper count is not used as search completeness. Source-role and decisive-facet closure determine readiness.
4. A new source does not reopen a terminal STOP candidate. It may reopen a nonterminal opportunity family or create a genuinely new candidate ID.
5. Method change and lane-count change are deliberately separated so a yield change is attributable and reversible.
