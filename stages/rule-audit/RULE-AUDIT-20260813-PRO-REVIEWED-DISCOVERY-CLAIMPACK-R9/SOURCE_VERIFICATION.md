# Source verification for method rationale

These sources justify evaluation design; none is a candidate-level novelty, headroom or feasibility source.

| Source | Verified status | Permitted process inference | Forbidden overclaim |
|---|---|---|---|
| Si, Yang & Hashimoto, *Can LLMs Generate Novel Research Ideas?* | ICLR 2025 formal paper: https://openreview.net/pdf?id=M23dTGWCZy | Blind, style-controlled expert evaluation is needed; self-evaluation and diversity need auditing. | LLM-generated ideas are generally better across fields. |
| Si, Hashimoto & Yang, *The Ideation–Execution Gap* | ICLR 2026 formal paper: https://openreview.net/pdf?id=Fllp8l6Puy | Paper-only idea scores do not substitute for later execution evidence. | A pre-Stage0 smoke test proves or disproves the scientific claim. |
| Kon et al., *EXP-Bench* | ICLR 2026 formal paper: https://openreview.net/pdf?id=KjgyAm383Z | Execution readiness needs separate measurement and exact environment contracts. | Its AI-experiment success rate transfers directly to systems/architecture research. |
| Ajith et al., *LitSearch* | EMNLP 2024: https://aclanthology.org/2024.emnlp-main.840/ | Heterogeneous retrieval paths and reranking can complement keyword search. | Its ML/NLP Recall@5 is a recall guarantee in this project. |
| Shahid et al., *Literature-Grounded Novelty Assessment* | SDP 2025: https://aclanthology.org/2025.sdp-1.9/ | Facet-based reranking can support related-work auditing. | Retrieval/reranking proves exhaustive novelty. |
| Chen et al., *ScienceAgentBench* | ICLR 2025: https://proceedings.iclr.cc/paper_files/paper/2025/hash/f12b4df26344f3be803c06b555252efe-Abstract-Conference.html | Static plans can overestimate executable autonomy; execution state must remain separate. | Benchmark completion is a universal AI-autonomy rate. |
| Jansen et al., *CodeScientist* | Findings of ACL 2025: https://aclanthology.org/2025.findings-acl.692/ | Code review and replication checks add information beyond paper-style review. | Automated experiments alone establish publishability. |
| Rethlefsen et al., *PRISMA-S* | JMLA 2021: https://jmla.pitt.edu/ojs/jmla/article/view/962 | Search sources, queries, dates and limits should be reproducibly reported. | Systematic-review completeness rules transfer unchanged to open research discovery. |
| Rasheed et al., *From Fluent to Verifiable* | 2026 preprint: https://arxiv.org/abs/2602.13855 | Claim–evidence traceability and contradiction visibility are useful design targets. | The proposed standard is settled field consensus. |
| Ji et al., *Style Wins, Substance Loses* | 2026 preprint: https://arxiv.org/abs/2608.01666 | Style perturbation is a useful robustness probe for LLM judging. | Its reported values generalize to this project's reviewers or domains. |
