# Raw-to-Brief Ownership Audit

## Existing policy boundary

`rules/ROLE_DISCOVERY.md` permits complete current union, strongest collision, complete genealogy, complete witness/interface, natural-corpus acquisition, main results and formal Q1/Q2 calibration to remain `BOUNDED_CLOSURE_DEBT` at raw. It also says Discovery and Stage 0 must not both be required to exhaust the same current-union/collision work; Stage 0 independently rebuilds and adjudicates it.

`rules/ROLE_MAINLINE.md` likewise states that finite fidelity gaps or bounded union/collision debt are routes into Stage 0 rather than scientific DROP/STOP, subject to no known direct fatal and a finite same-object closure route.

The Source41 S1 raw exposes an operational ambiguity: a lane can satisfy the raw contract, freeze a finite killer and still withhold a clean brief because Stage 0-owned work remains open. This can strand the only scientifically legitimate recall without improving Stage 0 precision.

## One bounded later-boundary recommendation

At Source44 or the first later safe assignment boundary, run exactly one six-lane assignment with an assignment-local `RAW_TO_STAGE0_OWNERSHIP_BRIDGE_V1`:

1. Retain the Source43 five-field identity and concrete-queue controls unchanged.
2. For each new evidence-qualified raw—without outcome-aware backfill—perform one bounded brief-readiness pass inside the existing lane, time, retrieval and resource envelope.
3. The pass may only:
   - pin one exact versioned natural/canonical/implementation carrier, or a deterministic one-project carrier selection rule;
   - confirm the already frozen exact object, atomic action/estimand, claim endpoint, same-object semantics, non-generic discriminator, minimum falsifier, full-cost dimensions and finite closure route;
   - record known contrary evidence and any known direct fatal.
4. If the exact carrier cannot be pinned, keep `NOT_ADMITTED_UNFROZEN` or `RQ_BACKLOG/SOURCE_CLOSURE_QUEUE` as appropriate. Do not manufacture a brief.
5. If those Discovery-owned fields are closed and no known direct fatal/current-source absorption/generic-only route exists, emit `CLEAN_STAGE0_BRIEF` while explicitly labelling complete current union, strongest paper collision, exhaustive genealogy, Q2 calibration, implementation and results as **Stage 0 or later debt**.
6. Stage 0 independently rebuilds collision/current-union/Q2. It may reject the brief; that rejection is the intended precision denominator, not evidence that Discovery should perform Stage 0 twice.

This bridge does not reopen Source41, backfill Source42, or modify Source43. It only makes the already written stage separation mechanically explicit for newly arising raws.

## Why this is the minimum change

- Adding more retrieval does not fix an ambiguous carrier selection rule.
- Weakening exact identity or queue concreteness would reduce auditability and risk repeat topics.
- Requiring Discovery to finish the full current union/Q2 review duplicates Stage 0 and starves its denominator.
- Automatically sending every raw would be too permissive; the exact carrier and Discovery-owned claim contract still must close.

## Acceptance metrics for the one-cycle pilot

| Metric | Required result |
|---|---:|
| `RELATED_ONLY` identity false exclusions | 0 |
| late historical identity reconciliation | 0 |
| zero-attempt falsely exhausted queues | 0 |
| ambiguous/disjunctive executable queues at first handoff | 0 |
| clean briefs missing exact/deterministic carrier | 0 |
| clean briefs bypassing a known direct fatal/current-source absorption/generic-only route | 0 |
| evidence-qualified raws receiving exactly one ownership disposition | 100% |
| Stage 0 result for any emitted brief | reported descriptively; no pass quota |

If the cycle has no evidence-qualified raw, the bridge is `NOT_EXERCISED`; it must not be called a pass or failure. If a brief enters Stage 0, compare its independent disposition with the frozen debt list. A Stage 0 rejection for a debt explicitly delegated to Stage 0 is informative and acceptable; a rejection because the exact carrier/action/same-object/full-cost contract was missing is a bridge failure.

## Rollback

After the single cycle, disable the bridge if it emits any brief without the required carrier/contract, hides a known fatal, or creates outcome-aware selection. Keep the identity and queue controls active. No candidate or historical state is migrated; emitted artifacts remain immutable and are handled by ordinary Stage 0 decisions.
