# 下一安全边界唯一建议

## `SOURCE48_TYPED_ACTIONABLE_RESIDUAL_PORTFOLIO_V1`

在 Source47 正常结束后的第一个安全 assignment boundary，仅运行一个六路周期。它不是新录取门，而是一个结果无关、预先冻结的题源/RQ 调度 profile。

### 1. 保留不变的控制

- v8.7、`RQ_REFINEMENT_STAGED_EVIDENCE_V1 / PRODUCTION`、V9 OFF。
- 六路 `gpt-5.6-terra/high`，lane 数、seed/RQ/raw/deep、检索和资源包络不增加。
- 五字段 identity、`RELATED_ONLY` 不排除、bounded/terminal identity 不复活。
- concrete queue、调用前计数、失败不作科学推断。
- same-object、current strong union/direct fatal、公平强基线、自然或 canonical carrier、full-cost、可复现性、Q2 与 claim ceiling 全部不变。
- 禁止 brief 配额、结果感知 backfill、看到 current-union 结果后换题。

### 2. 唯一行为变化：预先冻结 typed actionable-residual portfolio

在读取本周期决定性证据之前，各 lane 的 selected RQ 必须先选择一个可审计的“贡献残差类型”，并写出最小可推翻假设：

| Lane | 本轮 primary source/RQ 角色 | 必须在证据前写出的残差 |
|---|---|---|
| S1 | 当前源码/规范中的语义边界或矛盾 | exact target state、legality 或 semantic transition；不是 caller preservation/placement 口号 |
| S2 | 跨层瓶颈迁移 | 两层之间不可分解的 target-specific state/cost coupling；成熟 API/DSL composition 只作 negative control |
| S3 | 版本化自然或 canonical corpus | exact estimand、稳定结构假设、决策后果和 held-out falsifier |
| S4 | measurement/benchmark validity | exact benchmark/project/version、结论函数、排名/决策改变阈值、混杂与 full-cost validity boundary |
| S5 | theory/formal/approximation | 固定 guarantee、canonical instance family、oracle/checker 和非通用构造骨架 |
| S6 | 直接算法/编译器动作 | current action grammar 外的 target-specific state transition；不是既有 pass 的参数、排序或 wrapper |

这里的“角色”是检索投入安排，不是提案或录取配额。某 lane 无法形成上述 RQ 时必须留在 `RQ_BACKLOG`，不能用弱题填充。

所有 selected RQ 再做一个低成本、非结论性的 **label-stripping test**：去掉项目、ISA、产品和 API 名称后，如果候选只剩“选择/排序/绑定/复制/packing/scheduling/controller”，则在 evidence route 中把 `GENERIC_KERNEL` 设为首要 falsifier；不得靠重新加入目标名主张 target specificity。这个测试只决定先查什么，不单独形成科学 DROP。

### 3. raw 之后沿用 Source44 ownership bridge，不新增语义

对真正进入 `EVIDENCE_QUALIFIED_RAW` 的项，原样使用 `RAW_TO_STAGE0_OWNERSHIP_BRIDGE_V1`：

- Discovery-owned exact carrier/object/action or estimand/endpoint/non-generic discriminator/current locus/falsifier/full-cost 路线必须闭合；
- known direct fatal、current action absorption 或 generic-only route 仍淘汰；
- 只有 exhaustive current union、最强论文碰撞、完整小 witness、最终 Q1/Q2 与 Stage A fidelity interface 可作为显式 Stage 0 debt；
- 不把 Source44 RVV、Source45/46 raw 或 MLPerf open queue 自动回填、改名或重开。

Source44 的一个 brief 只证明该路由能制造可审计的 Stage 0 分母；RVV 尚未终裁，因此本轮仍是一次延长验证，不构成永久 shared-rule cutover。

### 4. 验收指标

不以“必须产生题目”为成功条件：

1. 6/6 lane 在证据前有唯一 typed residual role，或诚实登记无可回答 RQ；不得事后换 role。
2. 产品/API/DSL composition 不再占据 S2 的全部 selected RQ；它们可以作为预冻结 negative control。
3. 所有新 raw 的 `current action / generic kernel / exact carrier or estimand` 处置为 100% 可追溯。
4. 所有新 raw 获得且只获得一个 ownership disposition；缺 Discovery-owned 字段不得伪装成 Stage 0 debt。
5. 若形成 brief，独立 Stage 0 repair vector 不应出现本可在 Discovery 看出的 `ATOMIC_ACTION_UNCLEAR / OMITTED_FIRST_PARTY_FEATURE / OMITTED_GENERIC_KERNEL`；Stage 0 发现更深 current union 或 Q2 不足仍属正常。
6. 若 0 raw/brief，本轮记为 `NO_YIELD__PROCESS_METRICS_ONLY`，不启动结果感知补位，也不据此降低硬门。

### 5. 回滚

若该 profile 造成对象漂移、为了类型覆盖制造 filler、selected RQ 反而失去 exact carrier，或把 label-stripping 当成科学结论，下一周期直接回到 Source47 canonical baseline。保留所有 immutable 输出；不迁移、不删除、不重开既有状态。Identity、queue 与科学门不参与回滚。
