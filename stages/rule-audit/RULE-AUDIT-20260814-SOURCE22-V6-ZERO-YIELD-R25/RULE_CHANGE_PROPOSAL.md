## Problem statement

Source22 V6 的三个 trace 都正常证明动作可到 selector，却随后被 current union、同对象碰撞或 generic solver 淘汰；另外四路没有形成 trace，主要因题源在 raw/C0/D1 前就未闭合。S4 以论文自带 constructor 为主题，S1/S3/S5/S6 大量从成熟工具表面起题，S2 又把宽领域桶记为 raw。继续增加同类文献或扩大 action trace 只会加深已饱和表面，不能提高有效 brief 概率。

- 权威位置：`AGENTS.md` 的连续零产出自适应题源条款、`rules/ROLE_DISCOVERY.md` 的 source/current-union/D1 合同、R24 assignment-local V6。

### Exact raw admission

每条 raw 必须记录：

1. `carrier_identity_and_version`；
2. `same_object_problem_or_estimand_without_proposed_solution`；
3. `contribution_type_contract`；
4. `current_union_closure_route`；
5. `stock_or_formal_oracle_route`；
6. `primary_origin_role=PUBLIC_NATURAL_CARRIER`。

成熟 compiler/tool 或论文可以列为 `CURRENT_UNION / COMPARATOR / IMPLEMENTATION_CARRIER / ANCHOR / CONTRARY / SUBTRACTOR`，不得列为本轮 primary origin。paper-owned exact constructor 继续在 raw 前排除。

### Type-specific C0 entry

- `METHOD_COMPILER_SYSTEM`: current action source closed + same-object residual action + legal witness route。
- `MEASUREMENT_BENCHMARK_N3`: public panel/trace + fixed estimand + independent recomputation/oracle + unowned missing facet；不要求 native repair primitive。
- `THEORY_FORMAL`: canonical instances + strongest bound/baseline + checkable proof/falsifier route；不要求产品实现。
- `ARCHITECTURE_CROSS_LAYER`: public workload/model/interface + full-cost denominator + domain-native cross-layer action boundary。

所有类型在 D1 前仍须完成 current union、strongest subtractor、natural carrier、oracle、atomic action/observation skeleton、小 witness 与 full-cost 路线。缺实现或核心结果不淘汰；直接吸收、换对象、通用 kernel 或无有限闭合路线仍淘汰。
