## Type-specific semantics

### Target/action routes

`METHOD_ALGORITHM / COMPILER_TOOL / SYSTEM_ARCHITECTURE` 必须说明 union-external action 或新算法/保证为何非普通 mapping、selector、controller、placement、packing 或 generic wrapper。目标专属硬件题还需固定 workload、precision、interface、host/transfer/full-cost 与公平 current union；缺硬件只限制证据 ceiling。

### Measurement/benchmark routes

`MEASUREMENT_CHARACTERIZATION / BENCHMARK_DATASET / REPLICATION_NEGATIVE` 可以用 `MEASUREMENT_CONCLUSION_DELTA` 独立成文，不要求 controller action，但必须同时具备：

- distinct same-object estimand；
- unowned ranking/validity/coverage/regime/reproducibility/cost conclusion；
- independent validity subtractor；
- held-out、replication 或可复核 falsifier；
- conclusion/effect threshold 与 full-cost；
- natural 或 explicit canonical evidence ceiling。

synthetic canonical corpus 只能支持 suite/corpus 结论。自然部署主张必须另有自然证据。

### N3 and formal routes

- N3 若无 utilization mechanism，只能在 raw 时预注册为相邻 measurement conclusion route，保持同 object/carrier/estimand/evidence；禁止结果后重命名。
- THEORY_FORMAL 接受 formal canonical instances，但必须有非通用 construction、bound、certificate 或 impossibility delta；普通 solver wrapper 不合格。
