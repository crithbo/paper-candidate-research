# G01 depth red-team

## Minimal legal action witness

Two same-section elements `A` and `B` can only be reindexed if every typed relocation, public/private root reference, section-relative index, lazy decoder cache entry, linker relocation and fingerprinted output is correspondingly rewritten. The stock reader then decodes the same section/index protocol.

This has two exhaustive outcomes:

1. Recompute section indices and relocations while retaining the protocol. This is generic bitstream record/index packing, explicitly excluded by this assignment.
2. Change section partitioning, index granularity, deep-summary content, lazy decoding rule or importer/cache behavior. This changes the reader/protocol or package semantics and therefore changes the object.

No target-specific exact/FPT/Pareto/approximation algorithm remains under the fixed contract.

## Six-dimensional subtraction

| dimension | conclusion |
|---|---|
| decision | only generic element/index placement is free after writer/reader/linker union is frozen |
| information | package graph and compiler semantics fixed; no cache policy/profile controller allowed |
| complexity/resource | compile CPU/RSS/temp, export bytes, importer latency/RSS and cache path are fully countable but do not create an admissible action |
| quality/guarantee | deep import summary and stock unified importer behavior constrain sections/relocations together |
| full cost | future probe would include writer + archive + reader + cache materialization without omitting cache I/O |
| generalization/no-gain | Go standard-library/public module edges are natural, but cannot convert generic packing into N2 |

## Finite Stage A killer (not executed)

Pin Go and select 20–50 standard-library/public module dependency edges. Create a two-element relocation witness; use the stock importer to rebuild dependents and verify exported types, generic instantiation, inline-body access and fingerprints. Then measure compile CPU/RSS/temp, `__.PKGDEF` bytes, direct-import time/RSS and cache I/O. Stop if any semantic/import mismatch occurs or if the candidate is only index packing.

## Decision

`STRUCTURAL_DROP__ONLY_GENERIC_PKGBITS_INDEX_PACKING_OR_CHANGED_IMPORTER_PROTOCOL_REMAINS`.

This is not a resource/readiness conclusion.
