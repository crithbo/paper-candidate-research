## Interpretation discipline

An action gap in this matrix is a sourced structural hypothesis for independent Stage 0 attack, never a demonstrated result. Here, none survived. The MLIR row is not marked `STRUCTURALLY_UNCLOSABLE`: it is technically closable, but academic novelty is directly absorbed. No candidate is classified `READY_TO_CLOSE_IN_STAGEA`, `FINITE_FIDELITY_GAP`, `HUMAN_CORE_FIDELITY_GAP`, or `RESOURCE_BLOCKED_FIDELITY_GAP` because no candidate is retained.
