Six distinct exact objects were screened: gettext catalog, GCC PCH, GLib compiled schema, Cargo intermediate artifact, Go build-cache entry and TeX format dump.  They are distinct from prior S3 versioned layout objects and checked against the frozen registry/active assignments before review.

Each retained raw family has a finite natural plan: select 20–50 adjacent tagged/released objects from one public lineage, pin producer/runtime/platform, define a phenomenon before examining byte layouts, control direct semantic-change confounds, and test a contiguous held-out release tail.  The proposed rejection threshold is simple: if recurrence/locality disappears after the predeclared controls or fails on the held-out tail, the law is false for that carrier.

This finite fidelity route is sufficient in principle for a potential-first proposal only if it accompanies a named same-object N2/N3 constructor.  It does not itself constitute one.  No screened family provided a bounded current union plus target-specific, stock-legal whole-object utilization action; the two cache families are excluded by object/mechanism type.
