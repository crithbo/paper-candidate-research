# Unique opportunity family

## UOF-234-01 — version-aware kallsyms codebook construction

- **Exact same-object contract:** for each consecutive official Linux tag under one fixed architecture, fully pinned `.config`, compiler/linker/NM and deterministic build environment, encode that tag's selected `(address,type,name)` mapping in the stock kallsyms layout.  The unmodified stock kernel decoder must expand the proposed tables to the same relation and stock lookup behavior.  “Same mapping” means semantic equality separately at every version; it does not pretend successive releases have identical symbols.
- **Current source pin:** Linux upstream master commit `d58772d8520c7ef247c4b95c9bd76d3a25da9ff5`, resolved from the official GitHub API on 2026-08-11.  The pinned `scripts/kallsyms.c` uses global two-byte token profits and greedy selection; `kernel/kallsyms.c` decodes via token table/index; `scripts/link-vmlinux.sh` runs the iterative map/link/kallsyms construction.
- **Strongest same-information composition:** (1) the stock per-version kallsyms optimizer, provided `M_i` and also prior version `M_{i-1}, E_{i-1}` even though its fixed decision rule does not use them; (2) standard VCDIFF-style binary differencing between complete resulting images or kallsyms sections, with exactly the same previous bytes; (3) any stock build/link cost, no external cache excluded from accounting.
- **Union-external N2 action:** compute legal candidate codebooks for each `M_i`, then a sequence dynamic program over candidates which minimizes `image_bytes(E_i) + lambda * delta_bytes(E_{i-1},E_i)` (or the deployment-fixed weighted full-cost objective), preserving every version's decoder semantics.  It does not merely pick an encoder setting: it jointly constructs each codebook/name stream conditional on predecessor encoded state.
- **Static minimal witness:** consider `M_0` and `M_1` for which two legal current-version tables have local costs `c_1(A)<c_1(B)` but `delta(E_0,E_1(B)) < delta(E_0,E_1(A))` by more than `c_1(B)-c_1(A)`.  Stock greedy selects A because it sees only `M_1`; the joint objective selects B.  This decision-rule/information/quality witness is algebraic, not a claimed natural result.
- **Natural carrier plan:** 20–50 official adjacent stable tags, held out chronologically; preserve tag/tree IDs, source/config/toolchain hashes, `System.map`, `vmlinux`, kallsyms-section hashes and image/delta statistics.  The plan is finite and not executed in Discovery.
