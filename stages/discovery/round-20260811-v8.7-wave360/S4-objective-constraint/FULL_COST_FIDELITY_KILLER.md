# Full cost, fidelity, and finite killer

**Fidelity:** freeze source/destination manifests and current rsync pin; verify stock receiver reconstruction and metadata equality on a smallest natural-pair witness; enumerate both-end options and negotiation before any claim-bearing run.

**Full cost:** scan/signature/match CPU-RSS-temp; signature/control/network bytes; literal/matched data; receiver write/temp/disk; apply latency/RSS; metadata operations; whole-file verification; and any retry/invalidation work.

**72-hour killer:** reject if a pre-registered natural revision-pair set lacks a repeated normalized regime; if any candidate changes stock destination-tree/metadata semantics; or if its complete action maps to the frozen current union. The killer is unexecuted.
