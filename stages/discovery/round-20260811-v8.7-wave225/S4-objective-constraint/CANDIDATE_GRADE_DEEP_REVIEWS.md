# Depth review — V01

## Minimal native-legal action-divergence witness

Fix a root `R` with two same-space eligible non-root subgraphs. The stock depth-first/deferred serialization can emit `A, C, B`, where `A` and `B` reference a shared eligible object `C`. The proposed scheduler emits `A, B, C` only when existing pending-forward-reference, map-first, space, and deferred-object rules validate it. Both streams use existing bytecodes and reconstruct the same graph; their backref/hot-object tokens and post-deserialization allocation adjacency can differ. This is a whole serialization action, not an output flag.

## Six-dimensional subtraction

## Mechanism

`Constrained Snapshot Scheduling (CSS)` first contracts required serializer obligations (root/map prerequisites, snapshot space, read-only/shared boundaries, and deferred cycles). It then schedules only the ready objects using a bounded reference-local scoring structure that accounts for V8’s fixed hot-object window, backref token cost, alignment, and an explicit page-locality budget. The algorithm uses deterministic tie-breaking and emits the existing serializer bytecode; it is neither a generic ILP wrapper nor a profile controller. Semantic fidelity is enforced by the stock decoder rather than assumed.

## Finite fidelity closure / 72-hour killer

1. Pin V8 commit/build/target and freeze a 20–50 V8/Node carrier set.
2. Implement only the complete CSS action inside the serializer; retain stock reader and fixed compression.
3. First small witness: regenerate a snapshot containing the `R,A,B,C` shape; verify stock deserialization, graph identity relations, and JS behavior before timing anything.
4. Run the full carrier set and count mksnapshot CPU/RSS/temp, raw/compressed bytes, cold startup/deserialization, and RSS.
5. Stop immediately if any snapshot fails stock acceptance/equivalence, any legal schedule collapses to the current traversal union, or CSS is dominated under the full denominator.
