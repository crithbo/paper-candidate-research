# Candidate-grade deep reviews

## REKOR-PROOF-SHARING — `DROP__GENERIC_CSE_NOT_DISTINCT_N2`

The same object is a fixed bundle *set* with an all-valid decision; no certificate, identity or inclusion requirement may be weakened. A shared Merkle-node hash cache is only common-subexpression elimination over independently required native verification actions. It contributes neither a new verifier guarantee nor a source-backed non-generic action. Full cost includes all signature and identity checks, not just repeated hashes. Finite killer: two bundles with a shared path node but distinct leaves; reject if any signature/identity/proof outcome differs from independent native verification.

## OPENSSL-CHAIN — `DROP__CURRENT_UNION_AND_GUARANTEE_BOUNDARY`

OpenSSL currently builds and validates a chain from target, untrusted inputs, trust store and verification parameters. The official documentation explicitly warns that callbacks can waive required authentication checks and that check-order/error observations are not a stable policy interface. A proposed “better path” is absorbed by chain construction unless it changes purpose/trust/policy/acceptance semantics; the latter is a changed guarantee. Finite killer: a target with two intermediate paths under pinned `X509_VERIFY_PARAM`; drop if native building selects the path or the candidate differs in acceptance/return status.

## TUF-DELEGATION — `DROP__CURRENT_SEMANTIC_ACTION_UNION`

TUF’s role traversal, terminating-delegation, threshold-signature, expiry/version/hash conditions jointly define the acceptance action. Reordering role checks or memoizing already-valid metadata is a verifier schedule/cache, not an external N1/N2/N3 action; skipping a condition changes the security guarantee. Finite killer: one terminating and one non-terminating delegation with threshold signatures; reject on any target decision divergence or omitted validation dimension.

The three drops are structural. They are not inferences from absent implementation, resources, natural carriers, results, or AI readiness.
