# UNIQUE_OPPORTUNITY_FAMILIES

Six de-duplicated 2025 artifact-led families were screened: TileLink overlap compilation, KPerfIR compiler profiling, FastTree tree-attention runtime, CASS GPU translation, VOLT open-GPU lowering, and SIRIUS memory handover. The artifact establishes a natural carrier, not a residual by itself.

For the only potentially action-shaped rows, natural carriers would be respectively a distributed-model collective trace (R01), a Triton kernel plus compiler trace (R02), an SGLang prefix-sharing request trace (R03), a CUDA/HIP translation pair (R04), Vortex OpenCL/CUDA kernels (R05), and colocated inference/training traces (R06). Full cost would include compilation/JIT and host costs, all device/collective/memory traffic, synchronization, output/semantic checks, and native runtime overhead.

No row has a frozen minimal same-object witness followed by a complete union-external action. Therefore none is promoted to `CANDIDATE_GRADE_DEEP_REVIEW`.
