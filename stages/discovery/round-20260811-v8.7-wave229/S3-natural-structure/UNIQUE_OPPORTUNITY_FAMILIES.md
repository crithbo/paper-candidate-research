# Unique opportunity family

## UOF-229-01 — versioned Linux kallsyms token and name-stream relation

- **Exact object:** for a fixed official Linux tag, architecture and fully pinned `.config` (including `CONFIG_KALLSYMS`, `CONFIG_KALLSYMS_ALL`, address-base related selections and toolchain), map the selected symbol `(address, type, name)` entries to the in-kernel kallsyms representation consumed by the stock decoder/lookup paths.  It is not `/proc/kallsyms` policy, an arbitrary ELF symbol table, or a changed symbol set.
- **Current constructor/reader union:** current upstream `scripts/kallsyms.c` parses/screen symbols, sorts them, globally learns two-byte-token profits, greedily installs up to available token codes, emits names, 256-symbol markers, token table/index, offsets and name-order sequence.  `scripts/link-vmlinux.sh` derives a map using `NM`, invokes kallsyms through the link passes, passes `--all-symbols` and `--pc-relative` based on configuration, and validates `System.map` consistency.  `kernel/kallsyms.c` expands the stream through token table/index.  The v6.12 tag also shows the older absolute-percpu/base-relative variant; it cannot be silently conflated with current master.
- **Natural carrier / hash plan:** a bounded later Stage A would select 20–50 official adjacent stable tags, one architecture and one exact config/toolchain; record tag commit/tree identity, `.config` SHA-256, compiler/linker/NM versions, `System.map` and `vmlinux` SHA-256, and generated kallsyms-section byte counts.  Those artifacts were not acquired here.
- **Required law:** after controlling tag distance, selected symbol-count delta, architecture, exact config, toolchain, LTO/debug settings, generated linker stubs/trampolines and address-base mode, a held-out chronological group must retain a measurable token/dictionary or name-locality regularity.  Simple aggregate frequency is inadequate because the current algorithm already uses global token profits.
- **Conditional action:** a deterministic whole mapping constructor that exploits that stable law while emitting all stock-required tables and preserving stock decoder/lookup results.  An action limited to token ranking, an outer compressor, cache, or config switch is excluded.
- **Disposition:** `NOT_ADMITTED_UNFROZEN`: no controlled before/after law, exact release/config carrier set, or union-external whole action witness is frozen.
