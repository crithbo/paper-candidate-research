## Candidate-grade audits

### Qt RCC

Qt documents that `rcc` consumes a `.qrc` list to produce a binary `.rcc`, that a stock `QResource` can load/register it, and that the runtime exposes raw bytes. The current documented union already includes binary versus generated-source output, format version, root namespace and compression controls. A valid N2 would need a stateful target-profiled constructor over a *source-authorized* stock binary directory/index plus physical placement, with a stated exact/FPT/approximation/Pareto guarantee and a two-file stock witness.

The only presently named moves are file order, compression/alignment and documented options, or an unspecified generic packing/index replacement. They are forbidden by the assignment and do not establish a union-external atomic action. Qt current source ref retrieval was attempted but the upstream connection closed during read-only ref negotiation; documentation alone is insufficient to infer a missing writer action. Status: `NOT_ADMITTED_UNFROZEN`.

### GLib compiled schemas

GSettings documents XML schemas compiled into the `gschemas.compiled` binary form, loaded by schema ID and introspected for keys/paths. The natural CPU carrier can be a version-pinned GNOME application's installed schema set plus its XML/override history; the stock oracle is schema lookup and key/default introspection. A proposed target-aware schema-index and physical layout constructor would have to retain every schema/override and stock lookup result.

No current-source-authorized legal alternate compiled-index action was frozen. Compiler invocation and install/search path are existing configuration/deployment surface; a generic table layout or cache is not a target-specific N2. GLib `main` was source-pinned at `b865b41591b2d9457c4bac34511a3f59cf03df6c` on 2026-08-11, but the relevant compiler/reader action union was not enumerated without source-level closure. Status: `NOT_ADMITTED_UNFROZEN`.

### GNU gettext MO

The GNU MO format fixes sorted original-string descriptors, parallel translation descriptors, an optional hash table and alignment option. `msgfmt` is the producer and the GNU runtime reader is the oracle. A retained N2 would need a whole-file constructor that jointly chooses a legally variable, stock-reader accepted access structure and physical layout for a declared lookup distribution, while preserving all translations and lookups and supplying a non-generic algorithmic guarantee.

The documentation identifies precisely the existing hash/no-hash and alignment decisions, while logical entry order is constrained by sorted originals. No native legal two-file action divergence beyond generic packing/hash selection was frozen. The GNU upstream ref query did not complete after a TLS close; that operational fact is not a scientific negative conclusion. Status: `NOT_ADMITTED_UNFROZEN`.
