## D2 — GNU Emacs `.eln`: `NOT_ADMITTED_UNFROZEN`

Official Emacs documents `.eln` production/load paths, native-compilation functions and output/cache controls. It also directly states that native code is not transportable across systems and Emacs usually will not load `.eln` from earlier/later versions. Thus a three-version cross-release trace cannot assume a fixed stock reader: each point must be tied to its matching Emacs/host/libgccjit/assembler/linker ABI. The apparent cache recurrence is consequently not an N3 law.

Any action would have to be a complete native compilation construction—not a cache selector or external delta—and compare all `native-comp-eln-load-path`, async compilation and compiler/linker inputs. Full cost includes compilation/link CPU/RSS/temp, eln/delta bytes and matching runtime load/startup. 72h killer: demonstrate two matching-version legal outputs with identical loaded behavior and exhaust the native compiler pipeline. No witness or pinned natural chain is present. `NOT_ADMITTED_UNFROZEN`.

## D3 — GHC `.hi`: `NOT_ADMITTED_UNFROZEN`

Official GHC documentation says `.hi` is binary compiler information needed for dependent module compilation and warns that an interface not generated by the same compilation run as its object can lead to incorrect assumptions. Existing compiler behavior also retains identical interfaces and provides interface-diff/show commands. This is powerful contrary evidence against treating raw adjacent byte churn as a free layout residual.

The required natural trace must pin three GHC releases, source/options/object counterparts and the exact consumer compiler. A recourse law would need retained exported/interface fragments after controlling optimization (`-O`), ABI/hash and source dependency changes. A valid action requires a source-derived binary writer/reader union and two stock-compiler-equivalent interfaces—not a generic serializer. Full cost: compiler CPU/RSS/temp, interface/delta bytes and downstream compile/load. 72h killer: create/refute the witness and replay all interface writer modes. `NOT_ADMITTED_UNFROZEN`.
