## D1 — GLib resource bundle: `NOT_ADMITTED_UNFROZEN`

`glib-compile-resources` creates a binary bundle from an XML manifest and referenced files; stock `g_resource_load` / resource lookup fixes path-to-bytes semantics. A valid natural carrier would pin three adjacent official GNOME application releases, source manifest/blob hashes and resulting bundle hashes. The phenomenon must be measured as held-out retained path/blob cohorts after controlling manifest alias, compression and GLib version—no recurrence is claimed here.

Current union includes generated-source/static registration and binary-bundle paths; a legal two-output witness must preserve the complete namespace and stock lookup, and current serializer flags/source must be exhausted. Full cost: compile CPU/RSS/temp, bundle/delta bytes, load and lookup CPU/RSS/latency. 72h killer: three small official app releases, two source-equal resource paths and all writer modes; reject on changed lookup or native union replay. No whole action/witness/current union closure is present. `NOT_ADMITTED_UNFROZEN`.

## D2 — glibc locale archive: `NOT_ADMITTED_UNFROZEN`

The fixed function is matching-glibc locale-name/category selection through `setlocale`, with the same collation/ctype/messages/numeric/etc. outputs. Official glibc has `localedef` archive-generation code and documents locale selection; this is contrary evidence to an “unimplemented archive construction” claim. A natural triple must separately pin glibc code, locale sources/charmaps/aliases, localedef flags and archive hashes.

The proposed law is retained category payloads outside changed locale definitions, controlled for all those inputs; it is not measured. A candidate would need a locale-specific whole archive constructor and certified unchanged-category reuse while preserving reader behavior—not generic incremental build reuse or delta. Charge generator CPU/RSS/temp, archive/delta bytes and locale load/query costs. 72h killer: freeze three releases, verify matching `setlocale` behavior and enumerate localedef archive modes. Unfrozen action/witness/phenomenon ⇒ `NOT_ADMITTED_UNFROZEN`.

## D3 — OpenType fonts: `NOT_ADMITTED_UNFROZEN`

The object is a fixed font with the same character-to-glyph, glyph outline/metrics and required shaping/layout results under a stock compliant reader/shaper. The official spec uses a table directory with sorted tag records, offsets and checksums; font collections already share identical tables. This makes arbitrary table reordering, table sharing, DSIG handling or altered font identity non-actions unless strict reader results and required integrity semantics stay fixed.

A public three-release font family could test retained glyph/table cohorts while controlling design-source changes, variation axes, table checksums, DSIG, font compiler and shaping corpus. No stable law is claimed. A candidate would require a table-aware collection/share algorithm with an explicit exact/approximation guarantee beyond existing collections, then fair comparison to current font compiler/subsetter/collection builder plus VCDIFF. Full cost includes generation CPU/RSS/temp, font/collection/delta bytes and load/shaping CPU/RSS/latency. 72h killer: two legal same-answer outputs and complete native writer union. Neither action gap nor recurrence is frozen, so `NOT_ADMITTED_UNFROZEN`.
