# Candidate-grade deep reviews

## 1. veriT proof-producing SMT preprocessing — NOT ADMITTED UNFROZEN

veriT is proof-producing, and its published preprocessing work replaces coarse gaps with fine-grained proof rules. Same object is an SMT-LIB formula with identical unsatisfiability/theorem semantics and a proof accepted by the fixed checker/reconstruction path. A full action must choose and emit every simplification/normalization/lifting proof, not merely reorder assertions. The existing fine-grained proof-producing preprocessing is a direct subtractor. A source-pinned complete current rule/strategy/flag union and a union-external guaranteed schedule were not established.

## 2. SCIP exact MIP presolve plus VIPR — NOT ADMITTED UNFROZEN

SCIP exact mode uses exact rational/safe arithmetic and documents certificates checked by VIPR or a formally verified CakeML checker. Same object requires identical original MIP optimum/feasibility semantics, reduced model, exact solution lifting and checker result. Any rule scheduler must subtract current SCIP presolvers, transformation/lifting and certificate-emission union. No complete source-level union or legal action witness beyond current exact presolve/certificate mechanics was frozen.

## 3. CAQE certifying QBF preprocessing — NOT ADMITTED UNFROZEN

CAQE is a certifying QBF solver. A legal action would jointly schedule QBF reductions and certificate reconstruction while preserving quantified formula truth and checker-certified strategy/certificate semantics. The literature already treats preprocessing certification directly; current CAQE producer/checker flags and full preprocessing union were not closed. Generic clause ordering is absorbed.

## 4. QRATPre+ QBF preprocessing — NOT ADMITTED UNFROZEN

QRATPre+ is based on QRAT/QRAT+, a proof system specifically intended to cover preprocessing. A residual must be a complete new certificate-producing constructor with a formal nontrivial guarantee, not a generic preprocessing order. Full current producer/checker/option union and a minimal action-divergence witness were not frozen.

### SoPlex and certified MaxSAT

SoPlex provides presolving and exact rational solving, but this assignment requires an independently frozen proof/certificate emission, lifting and checker route; none was established. It stays `NOT_ADMITTED_UNFROZEN`, not a readiness DROP. Certified MaxSAT preprocessing is a direct same-object collision: it already proves broad preprocessing transformations end-to-end under a proof checker, so a generic certified-rule scheduling proposal has no residual without a new exact action/guarantee.

### Common natural carrier, full cost and 72-hour killer

Natural carriers: SMT-COMP SMT-LIB, MIPLIB instances, QBFEVAL/QBF Gallery and MaxSAT Evaluation benchmarks, all version-pinned in a later Stage A route. Oracle: native checker/reconstruction plus original-versus-reduced model/optimum/theorem equality. Ledger: preprocessing, solve, checker CPU/RSS; reduced and proof bytes; temporary storage; lifting/reconstruction latency. Kill if any rule is already expressible by the current union, reconstruction changes objective/theorem/model semantics, proof checker rejects, or the candidate is only an order/configuration sweep. No experiments were run.
