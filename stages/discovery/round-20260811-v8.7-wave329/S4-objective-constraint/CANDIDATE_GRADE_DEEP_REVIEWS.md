# Candidate-grade deep reviews

## D01 — Tree-sitter parser-generation/runtime regime

- **Exact object/oracle:** fixed Tree-sitter runtime ABI, grammar language semantics, generated parser accepted by the stock runtime, and identical concrete syntax tree/error behavior for the same source inputs.
- **Current pin and union:** Tree-sitter master `5c2533bb7bc83cff3732031b846939f79f9ff11a`. Official generation material documents generated `parser.c`, ABI choices, conflicts, state reporting, and `--disable-optimization`; parse material documents runtime parsing, edits, encodings, and grammar/library selection. The fair union includes generation/runtime defaults plus these documented non-default paths.
- **Natural regime schema:** pre-register 20–50 versioned grammars and their real source corpora. Stratify grammar states/conflicts/token structure and source length/edit shape; record generator CPU/RSS/temp, generated parser bytes, parser compile cost, full parse and incremental-edit CPU/RSS/tail latency, and tree memory. A cliff must recur across grammar families after normalizing grammar/source complexity; a `--disable-optimization` comparison alone is not a natural regime.
- **Required exploitation:** a semantics-preserving, target-specific joint parser-state/representation constructor with explicit complexity/guarantee, outside the complete current generator union. Generic table packing, a flag sweep, parser selection, or changed tree/error semantics fails.
- **Full-cost / 72h killer:** include generation+compile+parse+incremental update+memory. Reject if no normalized frontier discontinuity repeats, if the generated parser differs in stock parse/tree/error semantics, or if the entire action is generated by existing state merging/format options.
- **Disposition:** `NOT_ADMITTED_UNFROZEN__NATURAL_REGIME_UNMEASURED_AND_COMPLETE_CURRENT_GENERATOR_UNION_NOT_CLOSED`.

## D02 — ext4 HTree directory regime

- **Exact object/oracle:** same ext4 directory contents, inode/name semantics, feature flags, and stock ext4 lookup/readdir acceptance. No filesystem reader, hash-policy, or directory semantics may change.
- **Current pin and union:** Linux master `d58772d8520c7ef247c4b95c9bd76d3a25da9ff5`. Official ext4 documentation specifies linear and HTree layouts, index flag, hash variants, root/interior nodes, collision behavior, depth constraints, and metadata-checksum effects. The fair union includes compatible feature/hash/layout forms permitted by the current on-disk contract.
- **Natural regime schema:** pre-register 20–50 versioned public rootfs/package directory trees and reproduce matching images. Measure name distribution, entry count, hash collision indicators, tree depth, image bytes, construction CPU/RSS/temp, lookup/readdir tail latency/RSS, page-cache state, and fsck/metadata cost. Match filesystem block size, kernel, device/cache state, and directory-content distribution.
- **Required exploitation:** a stock-readable, semantics-preserving HTree construction algorithm that jointly controls full-cost/lookup Pareto behavior and is not a hash selection, mkfs/tune flag, generic B-tree packing, or reader replacement.
- **Full-cost / 72h killer:** include image construction, index bytes, lookup/readdir, cache, and check/repair costs. Reject if the regime disappears under matched name/entry distribution, if a candidate image violates stock ext4 semantics, or if the action reduces to current hash/feature/mkfs union.
- **Disposition:** `NOT_ADMITTED_UNFROZEN__VERSIONED_NATURAL_IMAGE_SET_AND_UNION_EXTERNAL_NATIVE_ACTION_NOT_CLOSED`.

## D03 — Bazel analysis-graph regime

- **Exact object/oracle:** fixed Bazel revision, workspace/repository state, target/configuration semantics, and stock loading/analysis result/action graph. No target selection, repository rule semantics, or output-quality change is allowed.
- **Current pin and union:** Bazel master `5dc60cedd5456112b1c21c577f94c041230be3ff`. The official build-phase material distinguishes loading and analysis; a complete source-level union over analysis caching, configuration transitions, flags, repository behavior, and action-graph construction was not closed in this desk review.
- **Natural regime schema:** pre-register 20–50 public Bazel workspaces/revisions. Record graph fanout, configuration-transition count, macro/rule shape, analysis CPU/RSS/temp, action-graph bytes, incremental invalidation/reanalysis cost, and downstream action reuse. Fix Bazel revision, external-dependency snapshot, platform, cold/warm state, target set, and storage cache; normalize by target and dependency-graph size.
- **Required exploitation:** a native analysis-graph constructor/algorithm preserving identical configured-target and action-graph semantics with an explicit complexity/guarantee. A remote-cache policy, target-selection controller, generic graph layout, or configuration flag does not qualify.
- **Full-cost / 72h killer:** count loading, repository resolution, analysis, graph materialization, invalidation, and downstream effects. Reject if the apparent cliff is an external-fetch/cache-state effect, if stock action graph semantics differ, or if source audit maps the action to current flag/cache/configuration union.
- **Disposition:** `NOT_ADMITTED_UNFROZEN__CURRENT_ANALYSIS_UNION_AND_NATURAL_REGIME_MEASUREMENT_NOT_CLOSED`.
