## Calibration analogs (not candidate evidence)

The nearest publication shapes are formal compiler verification (Tucker et al.; HEC), compiler-generated spatial data movement (MLIR-AIR), and concrete host-staging elimination (AXI4MLIR).  They confirm the domain can carry strong papers, but they also supply direct modern baselines.  No row is promoted merely because it has a public artifact or a plausible Stage-A implementation route.

## Full-cost and same-function boundary applied to every performance row

- Same function/quality would require bitwise or specified-tolerance output equivalence under the original program and input contract; compilation success alone is insufficient.
- The ledger would include code generation and tuning time, buffer allocation and lifetime, descriptor/program construction, host-device transfer, synchronization/barriers, fallback code paths, compilation cache state, and end-to-end latency/throughput—not kernel time alone.
- A fair comparison is within the exact compiler/runtime/backend object.  It may not treat AMD Tensor DMA as NVIDIA TMA, or `gfx1250` as CDNA5.
