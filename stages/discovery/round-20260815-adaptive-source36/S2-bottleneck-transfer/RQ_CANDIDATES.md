# RQ candidates — Source36 S2

All three questions preserve their exact object and endpoint across variants.

1. **OpenCL command buffer:** For a fixed multi-device OpenCL command graph and outputs, can a target-specific command-buffer construction provide a bounded guarantee outside command recording, multi-device queues and mutable dispatch?
2. **CUDA cluster DSM:** For a fixed CUDA kernel/outputs, can block-cluster formation and distributed shared-memory partitioning yield a whole compiler construction with a guarantee outside launch attributes and per-block shared-memory controls?
3. **CUDA programmatic dependent launch:** For a fixed two-kernel program and memory-order contract, can a dependency constructor improve full cost beyond programmatic-stream serialization and graph dependency-edge data?

Selected variants each ask whether a legal same-object action survives the current native union. No RQ was reformulated after the contrary check.
