# Source and collision matrix

Primary/current sources were used solely for current semantics. No implementation-absence claim is made in this batch.

| Family | Official reality record | Strongest same-object union | Action-gap / six-dimensional audit | Decision |
|---|---|---|---|---|
| WARC | [WARC 1.1](https://iipc.github.io/warc-specifications/specifications/warc-format/warc-1.1/) defines optional `revisit` records, identical-payload-digest and server-not-modified profiles, and reference headers. | Response/resource records plus all legal revisit profiles, digests and references; archive size, reference resolution and reader cost all count. | Decision/information: repeated payload identification and reference construction are native. Quality: same archived payload/capture fact. Full cost: digest, headers, reference lookup, storage. Generalization: no complete action beyond the standard profiles. | `DROP`: direct action-space absorption. |
| OSM PBF | Current [OSM PBF format](https://wiki.openstreetmap.org/wiki/PBF) defines independently decodable fileblocks, primitive groups, string tables, configurable granularity and preservation of entity order/tags in the reference serializer. | PBF/Osmosis serializer and compatible reader semantics; all encoder/decoder bytes/time/memory. | The natural structure is plausible, but no complete current source/config union or union-external legal action was frozen. A changed ordering/index could change reader/replication semantics. | `NOT_ADMITTED_UNFROZEN`, not a readiness-based DROP. |
| Wikimedia history | Official [Wikimedia dump availability](https://meta.wikimedia.org/wiki/Data_dumps/What%27s_available_for_download) and [MediaWiki XML import documentation](https://www.mediawiki.org/wiki/Manual:Importing_XML_dumps) establish full revision-history XML carriers. | Current XML dump/import semantics; an incremental-dump format exists but is documented as unfinished and not treated as a current stable union. | Candidate requires a same-reader/semantics-preserving delta layout. That object/union cannot be closed from official materials without inventing a new format, which would violate same-object. | `NOT_ADMITTED_UNFROZEN`. |
| CT | [RFC 9162](https://www.ietf.org/rfc/rfc9162.html) specifies append-only Merkle logs and inclusion/consistency proof semantics. | Standard individual proof request/verification actions, Merkle hash/path size, server CPU and verifier CPU. | A joint multiproof would change the response grammar/request object; retaining standard individual proofs gives no union-external constructor. Cohort path sharing alone is generic and not a natural N3 residual. | `DROP`: same-object failure/direct protocol absorption. |
| NVD | Current [NVD data feeds](https://nvd.nist.gov/vuln/Data-Feeds) and [CVE API](https://nvd.nist.gov/developers/vulnerabilities) offer 2.0 feeds, modified-since queries, pagination and same-answer retrieval. | Current API/feed date filtering, pagination and complete transfer/parse cost. | Modified cohorts are already addressable by native query condition. A batching/cache policy is a controller; alternate feed layout changes provider output object. | `DROP`: direct union absorption or prohibited controller. |
| SPDX | Current [SPDX specifications](https://spdx.dev/use/specifications/) identify SPDX 3.0 and official SHACL; [OMG SPDX 3.0](https://www.omg.org/spec/SPDX/3.0) supplies the model artifacts. | Standard SPDX document/model/validation and full serialization, validation and reference-resolution cost. | Cross-document factorization is an external storage/format wrapper unless it remains one standard-valid document, in which case no complete nontrivial action was named. | `DROP`: wrapper/object-change boundary. |

Dedup boundaries: Wave59 sparse/locality, Wave71 regime/trace, Wave81 Brotli/CDS/V8, and Wave90 Nix/Cargo/Debian/OCI were not reused. Active S1/S2/S4/S5/S6 scopes were also avoided.
