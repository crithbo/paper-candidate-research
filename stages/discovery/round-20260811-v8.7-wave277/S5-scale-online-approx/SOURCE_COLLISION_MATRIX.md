# Zarr v3 shard/index — source and collision matrix

| Facet | First-party current evidence | Frozen fair comparison | Decision |
| --- | --- | --- | --- |
| Same object | [Zarr v3 core](https://zarr-specs.readthedocs.io/en/latest/v3/core/v3.0.html) and [sharding-indexed spec](https://zarr-specs.readthedocs.io/en/latest/v3/codecs/sharding-indexed/) define array metadata, codec pipeline, shards, inner chunks and index. | Same schema, values, chunk/shard geometry, codec/checksum, store key and stock reader. | fixed; changing reader, representation or guarantee is invalid. |
| Native write action | The spec permits full encode, append-only replacement/index, and fixed-size random writes; inner order is unconstrained. | all three paths, not just a default writer call. | write-order/threshold policy is absorbed. |

| Store semantics | [storage guide](https://zarr.readthedocs.io/en/latest/user-guide/storage/) distinguishes Local, Zip, Fsspec, Memory and remote stores; the spec assigns synchronization to applications. | store-specific overwrite, range and publication behavior must be pinned before a constructor comparison. | current cross-store atomic recovery route is unclosed. |
| Action divergence | Relocate a bounded set of variable-sized live inner payloads, replace index, and certify dead-byte and relocation bounds per update. | not a selection among write orders; it must be a complete transition algorithm with a fixed publication protocol. | `NOT_ADMITTED_UNFROZEN`: legal format alone is insufficient. |
| Natural carrier | [official storage guide](https://zarr.readthedocs.io/en/latest/user-guide/storage/) names NOAA NWM Retro v2 public Zarr. | versioned updates of that one fixed array, not a static snapshot. | carrier is natural; versioned mutation trace remains unclosed. |
| Strong baseline/full cost | stock zarr-python complete rewrite, append-only, and fixed-size random-write path; unmodified reader oracle. | CPU, RSS, temporary space, shard/index I/O, requests, retained bytes, rewrite/delete bytes, query latency and recovery validation. | mandatory for any future closure. |
