# Non-evidence seed portfolio

These six seeds are ideation prompts only. They make no novelty, absence, or quality claim and are not locator/raw denominators.

| Seed | Structural prompt | Why it could expose a bottleneck transfer |
|---|---|---|
| S102-01 | Ahead-of-time binary metadata construction versus loader lookup | Faster code generation can shift cost to metadata materialization and access. |
| S102-02 | Host–accelerator command descriptor construction versus DMA completion | Compute offload can make descriptor lifetime and transfer ordering dominant. |
| S102-03 | Incremental compiler summaries versus downstream code-generation state | A local summary optimization can move cost to global reconstruction. |
| S102-04 | Persistent data structure update versus recovery validation | Fast writes can shift full-path cost to recovery/checking. |
| S102-05 | Runtime object serialization versus zero-copy reader access | Eliminating decode can reveal layout and verification costs. |
| S102-06 | Link-time compacting versus native unwind/debug lookup | Size reduction can shift cost to access-path construction and lookup locality. |

Network-security, exploit, vulnerability, and protocol-security topics were excluded at seed generation.
