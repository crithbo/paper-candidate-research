| Control | Expected routing | Result |
|---|---|---|

| Five-field exact terminal identity or frozen direct current collision | exclude before raw | PASS |

| Measurement or formal card without a non-product witness | use its type-specific anti-collapse check; no universal gate | PASS |
| First selected packet returns no closure | do not backfill after result | PASS |
