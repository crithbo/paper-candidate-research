# Candidate-grade deep review — CD-142-01

## Current strongest fair baseline union

For the same exact state-query contract, the comparison union is official OpenSky extraction (API/Trino/pre-curated dataset), exact predicate filtering, ordinary spatiotemporal index/encoding/storage and all parse/decode/selection costs. No prediction, route inference, interpolation, reconstruction or lossy simplification is a fair comparator without an explicitly changed quality contract.

## Confounds and law test

The smallest credible test must block/condition on receiver coverage, source type, message-rate/gap distribution, missingness, route, aircraft/airframe, origin-destination, altitude/phase proxy, region and local time. A law passes only when its statistic transfers to both held-out regions and held-out times above matching route/coverage nulls. This review finds no such existing official/paper statistic to cite as already established.

## Metric/full-cost denominator

- Exact query answer equality: selected state identifiers, timestamps and every requested field.
- Completeness/legality: field-presence/missingness masks and source metadata are preserved; no interpolation.
- Cost: extraction, build, representation bytes, index bytes, query/read/decode CPU, peak RSS and any validation cost.
- Quality: exactness is binary; a lossy route must separately prove its error/guarantee and is not this object.

## Small witness and ≤72h killer

If an authorized later step supplies a licensed, frozen 20–50-flight public/curated subset, schema/query/hash and a candidate action certificate, the first test must reject before performance claims if any holds:

1. official extraction and candidate do not return identical selected states/fields;
2. receiver/source/gap-matched permutations or a held-out region/time eliminate the alleged law;
3. the action is replayable by ordinary exact index/encoding union;
4. full-cost denominator has no residual.

No test is run here. The killer is finite but cannot close the absence of a current law/action witness.

## Decision

`NOT_ADMITTED_UNFROZEN`; no `STAGE0_BRIEF` or `PROPOSE_STAGE0`. The reason is structural: the law is not previously established under required controls and no union-external exact constructor is named. It is not a negative result or a resource/readiness rejection.
