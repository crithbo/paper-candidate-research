# Source35 question card

- **Identity:** fixed RISC-V MachineFunction, Zicond feature, ABI and behavior.
- **Oracle:** stock assembler/disassembler and program semantic equivalence.
- **Current-source locus:** current LLVM RISC-V usage guide and target backend
  source interface.
- **Natural carrier:** finite LLVM RISC-V test/corpus route.
- **Full cost:** compile CPU/RSS/temp, code bytes and later hardware execution
  costs only if separately authorized.
- **Minimum falsifier:** source pin shows only existing selector composition,
  or no target-specific whole guarantee can be stated.
- **Canonical result:** structural selector/current-union control; no raw.
