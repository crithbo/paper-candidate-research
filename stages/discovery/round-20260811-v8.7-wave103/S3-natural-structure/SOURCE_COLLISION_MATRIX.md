# Source and collision matrix

Only official/upstream sources were used. No statement in this matrix relies on an implementation being absent.

| Object | Current primary reality | Strongest executable same-information union | Full-cost / finite 72h killer | Decision |
|---|---|---|---|---|
| BAM/CRAM | [GA4GH HTS specifications](https://samtools.github.io/hts-specs/) define SAM/BAM, canonical CRAM v3.x, CRAM codecs and CSI/Tabix indexing. | Current CRAM encoder's container/slice/preservation-series/codecs, reference access and read/write/index pipeline. | On a frozen natural alignment subset, require reference-valid decode and identical alignment/header semantics; charge encode, decode, reference, index, bytes and memory. Reject if the entire constructor replays this union. Not run. | `DROP`: proposed block/codec construction is native CRAM construction. |
| PCAPNG | Current [IETF pcapng draft](https://datatracker.ietf.org/doc/draft-ietf-opsawg-pcapng/) defines capture block format, including interface description blocks and extensible blocks. | Parser/spec semantics are frozen, but a current reference writer's complete action set, flags and all legal option/block configurations were not frozen. | Freeze one public trace and writer tag/config; verify every packet/timestamp/interface; charge bytes, write/read time and options. Reject if no action outside union. Not run. | `NOT_ADMITTED_UNFROZEN`: no complete audited union/action certificate. |
| Zarr v3 | The official [Zarr sharding codec](https://zarr-specs.readthedocs.io/en/latest/v3/codecs/sharding-indexed/index.html) explicitly stores inner chunks in shards; the [core v3 specification](https://zarr-specs.readthedocs.io/en/latest/v3/core/v3.0.html) fixes chunk grids. | Chunk grid, shard shape, inner chunk shape, codec pipeline and standard reader; full storage/object-request/read cost. | Frozen public array, byte/value-equivalent read, storage plus request/read/decode/memory denominator. Reject if proposed global layout is expressible by the native grid/shard constructor. Not run. | `DROP`: direct action-space absorption, not mere configuration existence. |
| Android AAB/APK | Current [Android App Bundle format](https://developer.android.com/guide/app-bundle/app-bundle-format) defines base/feature/configuration APK generation; [apksigner](https://developer.android.com/tools/apksigner) verifies signatures and warns modifications invalidate them. | AAB module/configuration generation, APK split delivery, alignment/signing/verification and device configuration inputs. | Fixed AAB/device, verify installed resource/code path and signature; charge bundle generation, APK bytes, signing and install/read costs. A new split layout either replays native generation or changes signed artifact semantics. Not run. | `DROP`: native union absorption or same-object failure. |
| FITS | NASA's [FITS standard](https://fits.gsfc.nasa.gov/fits_standard.html) recognizes image/table compression; registered [tiled image compression](https://fits.gsfc.nasa.gov/registry/tilecompression.html) permits rectangular tiles and supported codecs. | Tiled image partition, legal algorithms and fpack/CFITSIO-style encoding/decoding, charged with bytes and CPU. | Frozen image, exact pixel/header readback, bytes plus encode/decode/memory. Reject if tiling/codec sequence is native. Not run. | `DROP`: direct current constructor union. |
| OpenEXR | The official [OpenEXR technical introduction](https://openexr.com/en/latest/TechnicalIntroduction.html) defines tiles, level modes, deep tiles, compression and reader/writer behavior; the open-source library is the format authority. | Tile size, level mode, compression, chunk order/buffering and reference reader/writer full cost. | Frozen EXR, exact channels/pixels/deep samples readback, bytes plus write/read/memory. Reject if all actions are tile/level construction already supplied. Not run. | `DROP`: direct current constructor union. |

Dedup check: no Wave59/71/81/90/98 object was reused; the earlier ORC line is explicitly excluded by the registry's terminal Wave13 result. S1/S2/S4/S5/S6 active objects were not adopted.
