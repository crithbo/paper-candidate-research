# Source37 same-object RQ variants

RQ formation precedes targeted evidence. The RQs below intentionally do **not** presuppose a complete current union, collision catalogue, witness, implementation interface, result, or Q1/Q2 decision.

## S01 — estimator decomposition (measurement characterization)

Object frame: one fixed versioned public accelerator benchmark result artifact and its declared run boundary.

1. For that artifact, does adding predeclared host setup, transfer, and teardown components alter the reported energy/performance estimand without changing the workload or device result semantics?
2. Under the same artifact, which component-level denominator is necessary for the conclusion to remain invariant across declared execution modes?
3. Can a precommitted full-cost estimator expose a validity boundary rather than merely report another metric?

## S02 — ranking counterfactual (benchmark dataset validity)

Object frame: one fixed versioned canonical benchmark result set, a stated population of tasks, and a ranking endpoint.

1. Does a predeclared held-out task stratum change the ranking stability of the result set under the same score semantics?
2. Can coverage-aware resampling identify a boundary where a published rank is not representative of its declared task population?
3. What minimum artifact metadata is required to falsify a claimed ranking invariance without changing the benchmark object?

## S03 — replication boundary (replication-negative)

Object frame: one fixed versioned public benchmark artifact, matching evaluation semantics, and a stated comparative endpoint.

1. Is a reported comparative conclusion reproducible across a predeclared artifact stratum while maintaining identical task, metric, and cost boundary?
2. Can a negative replication isolate whether any reversal is attributable to an observable artifact stratum rather than an implementation change?
3. What finite held-out artifact route can falsify the conclusion while preserving same-object semantics?

None is an evidence-qualified raw opportunity until a Question Card freezes an exact public carrier, source locus, minimum falsifier, finite closure route, and initial full-cost boundary.
