# Unique opportunity families

## Screening result

Six new native checked-proof families were screened against the same acceptance/result requirement. Two have an independent serial proof language (QRP and OpenTheory), but their producer/configuration unions have not been fully source-pinned and no complete union-external action is asserted. Four expose checked build artifacts or kernel proof terms, not a separately portable producer/checker stream with an admissible whole-action residual.

| family | fixed same-object carrier | public natural route | outcome |
|---|---|---|---|
| DepQBF QRP/BQRP | same QBF and same certified truth result | versioned QBFLIB instances and solver traces | NOT_ADMITTED_UNFROZEN |
| OpenTheory `.art` | same imports/exports and HOL theorem set | versioned OpenTheory packages/articles | NOT_ADMITTED_UNFROZEN |
| Lean `.olean` | same module declarations/theorems checked by kernel | versioned Mathlib modules | STRUCTURAL_DROP: build artifact, not independent stream action |
| Rocq `.vo` | same source events and kernel-checked theorems | versioned standard/community library books | STRUCTURAL_DROP: proof source/dependency construction is the object |
| ACL2 `.cert` | same book and certified event semantics | versioned ACL2 Community Books | STRUCTURAL_DROP: certificate attests to corresponding book/version |
| Isabelle proof term/theory | same theory context and theorem | versioned AFP/Isabelle theories | STRUCTURAL_DROP: reconstructed kernel proof is context-bound |

No family has a certified complete N1/N2 action outside its strongest same-information union; therefore no brief is formed.
