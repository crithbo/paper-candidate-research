# Candidate-grade deep reviews

Every row fixes output theorem/result and acceptance by the named native verifier. A valid later ledger is producer CPU/wall/RSS, checker CPU/wall/RSS, certificate/artifact bytes, temporary storage, and time-to-accepted-result; no row was executed.

## 1. DepQBF QRP/BQRP — NOT_ADMITTED_UNFROZEN

**Object/oracle.** Fixed prenex QBF and identical certified truth result, accepted by QRPcheck. DepQBF documents `--trace=qrp` and `--trace=bqrp`.

**Candidate action/witness.** A producer might globally order resolution derivations, quantified reductions and deletions while retaining the checked result. A smallest witness needs two reusable derived clauses with competing later resolution uses, where either release point changes live trace state.

**Union/decision.** The frozen official surface proves trace formats/output option, but this pass did not source-pin every producer derivation/deletion policy, trace flag and checker grammar. Generic deletion/order compression is also adjacent to excluded checked-deletion families. No union-external whole constructor or guarantee is certified: `NOT_ADMITTED_UNFROZEN`.

**72-hour killer.** Pin DepQBF/QRPcheck commits; enumerate trace/deletion controls and grammar; use a public QBFLIB witness; reject if postprocessing, a current mode, changed QBF/result, or no live-state/full-cost guarantee.

## 2. OpenTheory article stream — NOT_ADMITTED_UNFROZEN

**Object/oracle.** Fixed import assumptions and exported HOL theorem set. An `.art` article is a UTF-8 stack-machine command stream; OpenTheory and a verified Candle checker can check derived theory.

**Candidate action/witness.** Two independent lemmas consumed by one later theorem permit alternative command batching, sharing and stack lifetime while imports/exports stay fixed.

**Union/decision.** Public format material establishes the abstract machine and article concatenation, not a source-pinned complete producer action/config union or a certified action outside it. A batching claim could only be concatenation, generic proof compression or emitter rewriting: `NOT_ADMITTED_UNFROZEN`.

**72-hour killer.** Pin tool/checker versions; enumerate commands, package/concatenation operations and dependencies; create the two-lemma witness on a public package; reject if stock tooling expresses it, imports/exports change, or costs omit producer/checker dimensions.

## 3. Lean elaborated module / `.olean` — STRUCTURAL_DROP

Lean documents that elaboration kernel-checks every addition and serializes the resulting environment to `.olean`; `leanchecker` replays it. Declaration-order/environment sharing acts on module elaboration/build dependencies, not an independently specified proof stream accepted apart from that context. Reordering can change visibility/elaboration; serialization-only change is emitter optimization. Public Mathlib is a carrier, but no same-object stream residual exists. `STRUCTURAL_DROP__CHANGED_BUILD_OBJECT_OR_EMITTER_OPTIMIZATION`.

**72-hour falsifier:** pin Lean/Lake versions, imports and checker; reject a proposal requiring changed visibility/imports/elaboration or only artifact serialization.

## 4. Rocq/Coq compiled proof / `.vo` — STRUCTURAL_DROP

Rocq documents its kernel as a type checker and completed proofs as kernel-checked proof terms. A `.vo` is tied to vernacular events, imports and compilation state. Ordering/batching either changes the source proof/dependency object or is compiler/cache optimization, not a distinct certificate-stream N2. Public library files provide carrier/oracle but no separable whole action. `STRUCTURAL_DROP__NO_SEPARATE_SAME_OBJECT_STREAM_ACTION`.

**72-hour falsifier:** freeze compiler/kernel/import graph and a small public theorem; reject if the different stream cannot be accepted without replaying a changed source environment.

## 5. ACL2 book certificate / `.cert` — STRUCTURAL_DROP

ACL2 states `certify-book` creates a certificate and `include-book` inspects it; validity is tied to admissibility of that book's events and version/book hash. Record ordering/state sharing is inseparable from book/event/dependency construction; copying or renaming may require recertification. Community Books are a public carrier, but any candidate changes the book or makes a wrapper. `STRUCTURAL_DROP__CERTIFICATE_BOUND_TO_BOOK_AND_VERSION`.

**72-hour falsifier:** pin ACL2 version and a public book/cert pair; reject if reordered artifact fails hash/version binding or changes events/import semantics.

## 6. Isabelle proof term/theory — STRUCTURAL_DROP

Current Isabelle material states Pure can record theorem proofs as proof terms and a proof checker reconstructs/replays them through primitive inferences in the kernel, relative to theory context. Term ordering/sharing changes theory/proof construction context, is generic compression, or is internal representation. Public AFP/Isabelle theory is a carrier, but no independent same-object stream residual is established. `STRUCTURAL_DROP__CONTEXT_BOUND_INTERNAL_PROOF_REPRESENTATION`.

**72-hour falsifier:** pin Isabelle release/theory/proof setting; reject if changed theory, oracle boundary or postprocessing is required.

## Cross-row conclusion

No row reaches `TIER_B_Q2_VIABLE`. QRP and OpenTheory lack complete action-gap certificates; the other four fail same-object separability. This is not a claim that better proof producers are impossible, nor a readiness inference.
