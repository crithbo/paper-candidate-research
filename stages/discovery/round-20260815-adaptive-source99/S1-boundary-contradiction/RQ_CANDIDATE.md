# Research-question candidate

## Primary RQ — RQ99-01

For a fixed POSIX barrier, participant set and per-phase work, can a target-specific whole barrier/serial-section construction lower CPU, RSS or phase latency while preserving the standard's release, arbitrary serial-return and reuse/reset endpoint?

The question can survive only if its mechanism is not merely choosing which ready participant performs the serial section, batching barriers, or ordinary worker scheduling.
