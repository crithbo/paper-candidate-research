## Research question

For a fixed GCC target reservation description and CFG region, can a bounded set-state constructor retain the lawful reservation states reaching a join and emit conservative transitions with a target-specific exact/FPT or certified precision–size guarantee beyond the current generator composition?

## Canonical research claim package

- Exact object and contract: fixed GCC `.md` reservation semantics, fixed CFG and stock generated DFA hazard-recognizer semantics.
- Natural scenario: a public GCC release target description plus a two-predecessor scheduling regression selected in Stage0.
- Atomic action: canonical join-set state creation, pointwise stock transition lifting, state-set reduction/coarsening and generated transition-table emission.
- Information/assumptions: only reservation states, CFG join identity and target reservation horizon; no profile, changed ISA or changed scheduler objective.
- Fair comparator: deterministic/NDFA forms, minimisation/no-minimisation, comb-vector/no-comb-vector and the stock generated recognizer.
- Expected guarantee: exact conservative recognition for bounded interface cardinality/horizon, or a certified safe precision–space frontier.  This is a proposed proof target.
- Full-cost: generator CPU/RSS/temp, generated bytes, compile/scheduling time and recognizer precision/code-quality proxy.
- Failure region: unbounded state-set explosion, current equivalent union support, generic DFA-only recurrence or changed hazard semantics.
- Minimum falsifier: a current GCC action path emits the same join-set relation, or a public target `.md` cannot express the two-state witness without changing semantics.
