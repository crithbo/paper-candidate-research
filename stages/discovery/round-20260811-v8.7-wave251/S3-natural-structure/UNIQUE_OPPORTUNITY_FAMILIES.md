# Unique opportunity family

## UOF-251-01 — predecessor-aware jimage class-resource layout

- **Exact object:** for each adjacent official OpenJDK tag under one pinned platform/configuration and same selected module/resource/class logical set for that version, construct `lib/modules` so the unmodified stock `ImageReader`, `jrt:/` filesystem and normal launcher resolve the same resource paths and bytes.  No module contents, resource names, inclusion set, reader, class format or launch semantics may change.
- **Current source pin:** official OpenJDK `jdk` master `bc674c21af6123be4a247e758728de870aa96eb5`, resolved 2026-08-11.  Reviewed files: `ImageFileCreator`, `ImageReader`, `JlinkTask`, `OrderResourcesPlugin`, `JimageDiffGenerator`, and `ResourceDiff` at that immutable revision.
- **Current union:** jlink's complete plugin pipeline and all documented module-selection, `--compress`, `--strip-debug`, `--order-resources`, `--endian`, service and image options; current `order-resources` accepts patterns or an `@` path list, orders class/resource entries by ordinal then path, and leaves other entries in stream order.  Current `ImageFileCreator` serializes header, redirect/offset/location/string tables and content in resource-pool traversal order.  `JimageDiffGenerator` is an in-tree same-version packaged-module→optimized-image resource-diff facility, not the requested predecessor-version binary delta.
- **N2 action:** deterministically enumerate a finite `w`-bounded family of complete class-order lists accepted by `--order-resources=@list` over fixed class path-prefix/module blocks; non-class resources remain in the plugin's current canonical stream order.  For each version, materialize only the declared legal candidates; then a release-chain dynamic program uses the actual pairwise binary-delta costs to choose the sequence minimizing the deployment-fixed image/delta/read-startup objective.  It is exact over that explicitly declared bounded family, with no claim of unrestricted layout optimality; it is neither a generic ILP nor a selector.
- **Static two-version witness:** two legal class blocks `A,B` may be independently ordered by the current plugin from an input priority list.  Suppose the current local ordering puts `B` before `A`, but predecessor bytes align with `A` then `B`; where transition-delta savings exceed the bounded local layout penalty, the DP selects `A,B` and current per-version construction plus VCDIFF retains `B,A`.  Both pass the same reader oracle.  This proves decision-rule divergence, not natural improvement.
- **Natural plan:** later Stage A selects 20–50 adjacent official tags under frozen host/platform/build configuration, hashes source/tag/config/toolchain/JMODs and output `lib/modules`, and splits chronology for holdout.  It is not performed in Discovery.
