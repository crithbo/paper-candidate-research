# Topic brief — OPENJDK-JIMAGE-VERSIONAWARE-LAYOUT-DELTA

**Conditional tier:** `TIER_B_Q2_VIABLE`. **Route:** `N2` known-action joint algorithm.  No performance, natural-law or novelty-finality claim is made.

## Contract and contribution

Given adjacent official OpenJDK versions with a fixed platform/configuration and each version's unmodified logical module/resource/class set, output an ordinary jimage accepted by the stock reader, `jrt:/` filesystem and launcher.  The new action is a bounded-window, predecessor-aware **class-block** ordering constructor that produces the complete class list consumed by `order-resources`; non-class resources retain current canonical stream order.  It jointly costs current image, binary delta, and fixed read/startup terms while preserving all bytes returned for every logical path.

## Strongest fair baseline

Pinned current OpenJDK jlink complete plugin pipeline—including documented ordering/compression/strip/plugin options and current linkable-runtime diff facility—plus same-information VCDIFF/binary delta.  Required subtractors: no ordering, stock/documented order, per-version locally best order over the same bounded candidate family, and the joint DP; all use the same predecessor/current inputs and full cost ledger.

## Guarantee, natural route and killer

For fixed blocks and maximum displacement `w`, the constructor materializes a declared finite order family and chain-DP is exact over that family using actual pairwise delta costs; it makes no unrestricted layout-optimality claim.  Stage A uses 20–50 official chronological tags and frozen JMOD/source/config/toolchain hashes, stock byte/path oracle, full image/delta/build/temp/CPU-RSS/startup/read accounting and a later-release holdout.  Kill on semantic mismatch, direct reproduction by baseline union, changed-object/custom-reader dependency, unbounded frontier, or no held-out full-cost residual.

## Fidelity closure plan

Before any claim-bearing run, freeze exact JDK tag/source hash, `jlink --help --list-plugins`, all explicit/default plugin settings, module/JMOD carrier hashes, delta implementation/config, block partition, cost weights and oracle.  Discovery's static witness supports admission only.
