# Cross-lane exclusion boundary

This package excludes S1's fixed protocol/transaction/recovery-semantic objects, S5's online budget/rebuild/recovery-selection objects (notably FRACTAL, SBB, MemChannel, streaming/prefetch and flow-control), and all Wave62 exact objects (cloud EBS tail, ThinkAhead, MDK, RamRyder, Kareus, jwmalloc, Queue-Mem, HydraServe, Pyrocumulus and Svalinn). No revival of a terminal object is attempted.

The selected rows use different exact functions: failure-action dry-run semantics, BFT state-machine replication, elastic training interruption recovery, vCPU idle visibility, fleet maintenance, network transport, GC marking, failover capacity, robust certificates, and Wi-Fi MAC. Shared words such as recovery, SLO, tail, or robustness do not create a collision; the frozen object/action does.
