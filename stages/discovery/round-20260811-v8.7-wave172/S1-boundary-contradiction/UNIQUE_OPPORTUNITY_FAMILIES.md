# UNIQUE_OPPORTUNITY_FAMILIES

Six deduplicated native contracts were screened. They deliberately hold the policy/guarantee fixed: seccomp syscall decisions, Landlock ruleset rights, OPA decision semantics, SELinux type enforcement, component interface validity, and Kubernetes admission outcome. Their stock enforcer/verifier is the required oracle; a non-native userspace monitor, postprocessor, policy selector, or different threat model is not a same-object comparator.

No row yields a complete N1/N2 action outside its current compiler/artifact/verifier/enforcer union. R04 stays unfrozen because this bounded pass did not enumerate a pinned current SELinux policy-binary compatibility/configuration surface; this is not evidence that an action is absent.
