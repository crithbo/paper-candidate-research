# UNIQUE_OPPORTUNITY_FAMILIES — Wave 352

The following eight families are distinct at the exact stock object/reader level and were checked against the frozen registry and active scopes before screening.

| Family | Natural version chain | Same-object oracle | Stable-law closure route | Promotion outcome |
|---|---|---|---|---|
| Kotlin/Native KLIB | Official Kotlin compiler/library releases | Current Kotlin/Native library resolution and compiler consumption | Select 20–50 adjacent tagged libraries, stratify by target/dependency changes, hold out release intervals | Unfrozen action union |
| Dart AOT snapshot | Official Dart SDK tags and produced AOT artifacts | `dartaotruntime` target-matched loading | Tag-pinned target/platform strata; reject if recurrence vanishes after code/target controls | Unfrozen stock-legal action |
| Erlang BEAM | Official OTP release/module chains | OTP loader/code-loading and `beam_lib` inspection | Fixed compiler option and source-lineage strata; test held-out OTP intervals | Unfrozen union/action |
| Julia system image | Official Julia release series | Julia runtime system-image loading | Fixed platform/package-environment release strata; hold out minor releases | Unfrozen action; cache-only risk |
| R lazy-load database | Official R release/package artifacts | Stock R lazy-load/serialization reader | Serialization-version and package-lineage controls; held-out releases | Unfrozen union/action |
| LLVM coverage mapping | Official LLVM release chain | LLVM coverage tooling | N/A: prior profdata-family adjacency | Excluded |
| Nix nar/store object | Official Nix release/repository chain | Stock Nix store/nar reader | N/A: identity/reuse reduces to generic patching | Structural drop |
| Clojure AOT class | Official Clojure release artifacts | JVM class loader | N/A: scope/object overlap | Excluded |

None is promoted merely because a binary format admits multiple byte layouts.  The first five have finite prospective natural-law tests, but each lacks a currently frozen, target-specific, whole-object action outside the strongest current union.  They therefore remain raw rather than being recast as N2/N3 proposals.
