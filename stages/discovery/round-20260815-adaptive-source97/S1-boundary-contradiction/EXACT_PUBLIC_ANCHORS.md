# Exact public anchor

## A97-01

- Exact identity: Java SE 25 `java.util.concurrent.ExecutorService`, `close()` / `shutdown()` / `shutdownNow()` / `awaitTermination()`.
- Version/date: Java SE 25 API, retrieved 2026-08-15.
- Primary source: <https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/util/concurrent/ExecutorService.html>
- Observable endpoint: for a fixed set of already submitted tasks, whether they execute, are cancelled, terminate, and are observable through the specified `Future` / termination API after a shutdown action.
- Why this is an anchor rather than a novelty claim: it fixes the native contract and a public, CPU-executable carrier; it says nothing about an unclaimed residual.
