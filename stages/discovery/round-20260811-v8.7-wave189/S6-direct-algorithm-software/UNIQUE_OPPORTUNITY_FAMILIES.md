# Unique opportunity families

Each family fixes the source program/specification/rewriting or hardware instance, target artefact, and the native proof-kernel/checker or semantic oracle. A candidate may alter only internal, dependency-linked transform choices while preserving exactly the same input/output semantics and checker's acceptance.

The generic minimum action witness is two legal, independently applicable transforms whose order yields different internal intermediate artefacts yet the same checker-accepted semantics. This is a legality witness only. An admissible N2 would require a complete non-local constructor—e.g. globally coordinated pass/representation choice—with a formal complexity, approximation or semantic-guarantee increment beyond the current producer union. Generic matching/ILP, pass ordering, postprocessing or an altered target/checker is excluded.
