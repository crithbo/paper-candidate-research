The two frozen capsules are source origins only. Neither asserts novelty, an implementation gap, or a positive research outcome.

| Capsule | Frozen artifact / selection rule | Intended exact locator | Source25/26 cooldown | Use boundary |
|---|---|---|---|---|
| `S1_OPENMP60_OFFLOAD_SEMANTIC_BOUNDARY` | OpenMP 6.0 (Nov. 2024) plus 2025 errata; current Clang/OpenMP paths | one fixed OpenMP host-device program with target data/async completion observables | different from Source25 OpenMP detached-task endpoint and Source26 MOPS/Zfa surfaces | spec and current implementation are anchor/union/contrary only |
| `S1_RISCV_PSABI_1_1_CURRENT_CALL_BOUNDARY` | psABI 1.1 prerelease 2026-07-01 or newer with exact source commit to be pinned | one fixed RISC-V ELF function-call/unwind boundary | different from Source25/26 RVV/Zfa endpoints | ABI spec, compiler/linker source, and official ABI test are carrier/comparator only |

No capsule is admitted solely because it is versioned, official, or novel to this lane.
