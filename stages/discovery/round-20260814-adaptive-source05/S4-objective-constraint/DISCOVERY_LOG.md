## Targeted closure A — pgbench

**Exact object:** a fixed PostgreSQL version, database state, `pgbench` script and client-visible transaction semantics, with the stock `pgbench` result protocol. The current official documentation exposes `--rate` Poisson scheduling, schedule lag, `--latency-limit` skipped work, `--max-tries` retry/failure accounting, aggregate logs, per-statement reports and the distinction between initial connection and reported TPS. It additionally warns that logging/per-statement timing can itself reduce TPS.

**Candidate correction tested by source subtraction:** an attempt-complete SLO/capacity score that jointly accounts for successful, skipped, retried and failed attempts. **Contrary/current-union evidence:** all the necessary primitives are stock output under existing flags; constructing a score or choosing a reporting cutoff is an aggregation/policy choice, not a new same-object action. A target-specific estimator, formal bias bound, or non-controller mechanism was not identified.

**Disposition:** `DROP__CURRENT_TELEMETRY_UNION_ABSORBS_REPORTING_CORRECTION`. This is a structural result, not a conclusion from missing execution. A finite 72-hour falsifier for any later claim is simple: fix script/database/rate/clients/retry/latency-limit; if the alleged new decision is reconstructible from stock logs and an existing aggregation, it is absorbed.

## Targeted closure B — Isabelle

**Exact object:** fixed Isabelle/Pure theory, theorem statement and trusted inference-kernel semantics. Current official implementation documentation distinguishes implicit proof terms in the kernel from fully reconstructed proof terms expected by the proof checker. This gives a genuine formal cost boundary, but not yet a proposal.

**Required action/guarantee:** a target-specific constructor that maps proof obligations to reconstruction/checking artifacts while preserving the exact theorem and kernel acceptance, with a nontrivial theorem simultaneously bounding proof bytes and reconstruction/check cost relative to a named stock construction. Generic proof compression, external post-processing, generic Pareto solving, or changing the checker are excluded.

**Disposition:** `NOT_ADMITTED_UNFROZEN`. The official material does not, by itself, close the complete current producer/config union, public versioned natural theorem carrier, a union-external atomic constructor, or the required guarantee. This is not a resource, implementation, or result rejection. A finite Stage-A closure would pin one Isabelle release/library corpus and stock checker, enumerate current proof reconstruction/config routes, then reject the candidate if its action is representable by that union or loses theorem/kernel identity.
