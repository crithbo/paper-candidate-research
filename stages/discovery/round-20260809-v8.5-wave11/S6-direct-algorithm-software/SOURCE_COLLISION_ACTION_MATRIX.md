## Stage-A-yield-aware conclusion

The target gate requires a complete atomic action, native semantics, real comparator, one denominator with all relevant costs, and a finite public natural falsifier. The cvc5 sharing seed fails before implementation because native output/checker fidelity is unclosed; Bazel fails because the only remaining action is already a cache policy. Neither lack of a measured gain nor lack of implementation supplied these drops.
