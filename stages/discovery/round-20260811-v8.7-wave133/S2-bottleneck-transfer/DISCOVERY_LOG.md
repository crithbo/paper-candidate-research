### LAMMPS — `NOT_ADMITTED_UNFROZEN`

**Natural corpus:** first-party `bench/` inputs, examples and potentials span multiple molecular systems. **Frozen object/full cost:** same physical trajectory/thermodynamic outputs; neighbor build + force/compute + communication + integration + I/O. **Potential N3 law:** as a given compute kernel is accelerated, neighbor/communication fraction increases monotonically with surface-to-volume and skin/rebuild state. **Competing explanations:** potential style, precision, rank topology, GPU/CPU package, neighbor settings, hardware/network and problem size all co-vary. **Current baseline:** current LAMMPS packages, neighbor/communication controls and official benchmark inputs.

Neither the corpus’s published trace schema nor a pre-registered confound-control plan was frozen here. **Finite StageA killer:** 20–50 official benchmark cases blocked by potential and hardware; reject the law if a model including potential/rank/package removes the transfer effect or held-out systems reverse it. ### GROMACS — `NOT_ADMITTED_UNFROZEN`

**Natural corpus:** official nonbonded benchmark/evidence artifacts and released test systems. **Frozen object/full cost:** same molecular-dynamics trajectory/energy tolerance; domain/PME/force compute + communication + GPU runtime queues + output. **Potential N3 law:** GPU force acceleration exposes a predictable crossover to PME/communication/queue overhead at a normalized rank/system-size boundary. **Competing explanations:** GPU architecture/runtime version, queue configuration, ranks, PME decomposition, host binding and benchmark system.
