## Certificate rules

An action-gap certificate must name an exact legal construction action not expressible by the frozen strongest union under the same input information, output contract, verifier, and full-cost ledger.  `EMPTY` is a valid negative certificate for Discovery; it is not an experimental failure or a claim that no future method exists.

No `TOPIC_BRIEF` is emitted because no row has a non-empty certificate.  Naming a Stage-A killer without that certificate would be an unfair invitation to benchmark an absorbed action.
