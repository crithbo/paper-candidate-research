# SOURCE_COLLISION_MATRIX

All cited items are official project documentation/source locations, accessed by 2026-08-11. “Open” is an evidence boundary, not an absence claim.

| Family | Official current/source evidence and semantics | Current union / flags or config checked | Collision / counterevidence | Disposition |
|---|---|---|---|---|
| RPM | [RPM format](https://rpm.org/docs/6.0.x/manual/format_v3.html), [current tags](https://rpm.org/docs/latest/manual/tags), [payload flags](https://rpm.org/docs/latest/man/rpm-payloadflags.7) | `rpmbuild` payload compression flags; signing/digest header/payload relation | Signatures/digests bind emitted physical object; re-sign is not same fixed artifact identity. | Drop |
| APEX | [AOSP APEX](https://source.android.com/docs/core/ota/apex) | APK signature plus payload-image signature; package identity/version | Whole package/payload signing makes a layout rewrite observable in the guaranteed installed object. | Drop |
| DEX | [AOSP DEX format](https://source.android.com/docs/core/runtime/dex-format), [instruction formats](https://source.android.com/docs/core/runtime/instruction-formats), [ART source](https://android.googlesource.com/platform/art/+/refs/heads/main/dexlayout/) | `dexlayout`, dex-file reader/writer and `dex2oat` modes must be source-pinned; checksums, compact-dex and verification are counterevidence | Format supplies a hypothetical legal witness, but native layout tooling may absorb it. Exact option/source enumeration remains open. | Unfrozen |
| Rust rmeta | [rustc rmeta API](https://doc.rust-lang.org/stable/nightly-rustc/rustc_metadata/rmeta/index.html), [metadata fs API](https://doc.rust-lang.org/stable/nightly-rustc/rustc_metadata/fs/index.html), [rustc output options](https://doc.rust-lang.org/rustc/command-line-arguments.html), [official source tree](https://github.com/rust-lang/rust/tree/master/compiler/rustc_metadata) | `--emit=metadata`, `--out-dir`, `-C extra-filename`; exact metadata/incremental flags must be pinned | `METADATA_VERSION`, encoder and lazy tables show current producer ownership and no stable external contract. | Unfrozen |
| CPython pyc | [importlib](https://docs.python.org/3/library/importlib.html), [py_compile](https://docs.python.org/3/library/py_compile.html), [CPython importlib source](https://github.com/python/cpython/blob/main/Lib/importlib/_bootstrap_external.py) | `PycInvalidationMode`, `SOURCE_DATE_EPOCH`, `--check-hash-based-pycs` | Existing producer/reader covers cache generation; docs deny bytecode-specific API. | Drop |
| Signed kernel module | [kernel module signing](https://docs.kernel.org/admin-guide/module-signing.html) | `CONFIG_MODULE_SIG`, `CONFIG_MODULE_SIG_FORCE`, `CONFIG_MODULE_SIG_ALL`, hash/key options | Kernel verifies a signature over the entire module, including debug data; strip/re-layout after signing is forbidden. | Drop |

Baseline delta comparator for every still-open row: [RFC 3284 VCDIFF](https://www.rfc-editor.org/rfc/rfc3284), with the predecessor provided equally to the native constructor and delta tool. No survey/future-work item is used as evidence of a current implementation gap.
