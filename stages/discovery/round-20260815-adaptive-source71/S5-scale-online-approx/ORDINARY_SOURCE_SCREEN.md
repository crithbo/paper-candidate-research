## Same-object screen

S71-01 holds input artifact, transformed output and consuming variant semantics fixed. The public native mechanism supplies resolution, invocation and cached reuse, but it does not define a target-specific delta-transform action: the transform's algorithm is provided by a user action. A proposed incremental constructor would consequently be either:

1. a paper-owned/custom TransformAction, which is not a current native partial primitive;
2. generic archive/bytecode delta processing; or
3. a change of output/variant semantics.

Each branch fails the contribution contract before raw. No source absence was asserted, no future-work statement was used, and no implementation/result/resource limitation informed this disposition.

Disposition: EXCLUDED_BEFORE_RAW__PAPER_OWN_CONSTRUCTOR_OR_GENERIC_KERNEL.
