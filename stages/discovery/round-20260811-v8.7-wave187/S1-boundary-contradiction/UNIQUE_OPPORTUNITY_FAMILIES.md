# UNIQUE_OPPORTUNITY_FAMILIES

Six non-GPU hardware/software state contracts were screened. Fixed semantics mean identical ISA-visible state and program result under the same ABI; merely choosing `-march`, ABI flags, an emulator patch, or a different ISA/profile is excluded. Official sources checked: [RISC-V V](https://github.com/riscvarchive/riscv-v-spec), [LLVM](https://github.com/llvm/llvm-project), [QEMU](https://github.com/qemu/qemu), [CHERI](https://www.cl.cam.ac.uk/research/security/ctsrd/cheri/), [CXL](https://computeexpresslink.org/).
