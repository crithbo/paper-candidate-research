# Candidate-grade deep review

## D01 — QUIC 0-RTT replay-certificate index

- **Structural paper potential:** `TIER_B_Q2_VIABLE` conditional on the closure plan. N2 is a target-specific data structure/algorithm: retain TLS/QUIC replay safety while optimizing bounded replay-certificate state and decision work under fixed ticket lifetime, transport parameters, and early-data semantics.
- **Current evidence readiness:** `FINITE_FIDELITY_GAP`; no implementation or performance result is claimed.
- **Exact same-object contract:** same server endpoint, TLS resumption tickets, QUIC transport parameters, HTTP early-data trace, acceptance/rejection semantics, and at-most-once replay-safety guarantee. A false acceptance is illegal; a protocol or threat-model change is out of scope.
- **Current strongest union (to pin):** current TLS-library early-data callback/anti-replay interfaces plus the QUIC stack's ticket, token, transport-parameter and early-data paths, including all defaults and explicit options. ngtcp2 upstream documents resumption and 0-RTT test/client paths; it is an entry point, not proof of absence in any TLS backend.
- **N2 algorithm and guarantee:** model each presented early-data ticket by an authenticated epoch/key and constrained QUIC context. Construct a replay-certificate index with deterministic expiry and lookup transitions. Stage0 must either state an exact bounded-state optimum, FPT algorithm parameterized by active epochs, or an approximation bound against the same-information baseline. It must prove no duplicate acceptance under the fixed trace model and name the no-gain case where the stock union already supplies an equivalent index.
- **Natural carrier / oracle:** public ngtcp2 HTTP/3 examples and upstream tests; TLS transcript/QUIC packet trace plus server acceptance log is the oracle. StageA must use a public benign replay trace only; no adversarial deployment is needed.
- **Full cost:** certificate-index bytes/RSS, lookup CPU, cryptographic verification work, accepted legitimate 0-RTT fraction, rejected duplicate count, handshake/early-data latency, and compile CPU/RSS.
- **Finite fidelity closure plan:** (1) pin one BoringSSL/OpenSSL/other supported backend and one ngtcp2 commit; (2) enumerate callback, ticket, token, early-data, anti-replay and default/non-default option union; (3) freeze two legal first/replay traces and backend oracle; (4) search primary 0-RTT anti-replay papers against that exact union; (5) reject if it is a callback/controller, a generic cache, or direct absorption; otherwise freeze algorithm, comparator and cost denominator.
- **72h killer / stop condition:** after source enumeration, stop this proposal if a stock supported anti-replay mechanism already implements an equivalent same-information epoch/index guarantee, or if the only viable action is backend policy/callback selection. This is finite and does not require a positive result.
- **Novelty status:** `SEARCH_BOUNDED_OPEN`; no current-absence or publication-novelty conclusion is made.
