# Candidate-grade deep reviews

## CUDD

First-party anchor: [CUDD source](https://github.com/ivmai/cudd). Function-equivalent BDD orders give a static witness, but a global order/reorder guarantee is directly in BDD ordering research. The complete current reordering/default/non-default union has not been frozen. Finite killer: pin source/options, verify two equivalent BDDs, replay native reorders on a public circuit set and reject on absorption or generic ordering. `NOT_ADMITTED_UNFROZEN`.

## ABC

First-party anchor: [Berkeley ABC](https://github.com/berkeley-abc/abc). The project itself supplies batch command sequences and an equivalence flow, making a natural same-object route plausible. It also contains multiple current mapping and rewriting actions, so a one-script comparison would be weak. Complete command/config union and direct mapping collision remain open. Finite killer: source-pin, fixed library and circuits, equivalent output check, full CPU/RSS/area/depth ledger. `NOT_ADMITTED_UNFROZEN`.

## clangd

First-party anchors: [LLVM source](https://github.com/llvm/llvm-project) and [clangd project](https://github.com/clangd/clangd). Background shards support a stock navigation oracle but their current serialization/configuration and collision with source-index construction need source-level closure. Finite killer: pin source/config, two index outputs, stock navigation/digest equality and index/query full cost. `NOT_ADMITTED_UNFROZEN`.
