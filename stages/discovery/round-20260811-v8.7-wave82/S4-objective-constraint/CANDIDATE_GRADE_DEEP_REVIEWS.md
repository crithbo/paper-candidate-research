# Candidate-grade deep reviews

## POWER-CRASH-CORRUPTION — `DROP_DIRECT_ABSORPTION`

The exact object is persistent KV/notary behavior under crash and media-error conditions; primary quality is crash consistency plus corruption detection. PoWER already joins both constraints through API-write preconditions and a corruption-detecting Boolean, with two verified systems. The same-information union therefore contains those full proof/construction actions. The denominator includes normal writes, ordering, checksum atomicity, recovery, proof time and PM performance. A new scalar risk score or checker would be wrapper work. A finite killer would verify 20–50 small write/crash/corruption histories under identical API semantics and reject an action expressible by PoWER; no distinct atomic action exists. Direct absorption—not implementation/readiness.

## WOLVES-WOFS — `DROP_DIRECT_ABSORPTION`

The object is a file-system operation with unchanged synchronous crash-consistency semantics. WOLVES already constructs checksum-protected metadata packages, one ordering point and package translation/recovery—precisely the coupled recovery-versus-I/O action. The fair union includes all package construction and recovery paths, while full cost includes data/meta writes, CPU, ordering, space and post-crash recovery. Reweighting latency and write count is not N2. A finite killer would replay 20–50 filesystem operation/crash witnesses and require exact recovery while remaining outside the write-once package action; none is frozen. Direct absorption.

## F2FSJ-RECOVERY — `DROP_DIRECT_ABSORPTION`

The fixed object is F2FS state after normal/crash execution with the same file data/metadata consistency. F2FSJ's complete action comprises metadata-only ordered journaling, inode-embedded decentralized logs, epoch/data-control decoupling and fast-forward apply. It already binds recovery quality to I/O, contention and latency. The full denominator is every data flush, metadata write, journal transfer/apply, lock, recovery time and resulting state. An alternate epoch value or journal priority is tuning, not a new constructor. A finite kernel witness suite can check 20–50 crash histories; no union-external atomic action was identified. Direct absorption.

## SHIFTLOCK-RDMA — `DROP_DIRECT_ABSORPTION`

The fixed object is one-sided RDMA reader-writer locking with starvation freedom and fault tolerance. ShiftLock already jointly uses direct client-to-client handover and a nonblocking protocol to couple tail latency, goodput and RNIC resource use without weakening lock semantics. The fair union is its protocol plus established RDMA locks under the same contention/failure information; full cost contains lock/retry traffic, RNIC IOPS, waiting/tail, CPU, goodput, recovery and transaction behavior. A risk-sensitive scheduling rule only selects within that action space. A finite killer would replay 20–50 contention/failure schedules and require an action outside handover while preserving the contract; none is specified. Direct absorption.
