# UNIQUE_OPPORTUNITY_FAMILY register

| Family | Frozen guarantee / atomic action considered | Current strongest same-object union | Natural artifact and full-cost denominator | Status |
|---|---|---|---|---|
| Wasm binary | Decode all legal encodings to the prescribed abstract module; validate before execution. Atomic action: select a legal equivalent binary representation. | Spec-defined decoder/validator, legal encoder choices, and native compile/instantiate pipeline. | Public `.wasm` modules from compiler outputs; bytes, parsing/validation/compilation, instantiation, runtime, and exact validation/execution outcome. | Deep. |
| Avro | Resolve a datum using stated writer and reader schemas exactly as specified. Atomic action: choose resolution traversal/order. | Spec schema-resolution rules, current Avro reader/writer implementations and schema metadata. | Public Avro object-container files and evolving schemas; schema parse/fingerprint, encode/decode, codec I/O, memory, result/error behavior. | Deep. |
| Lean | Elaborate a declaration to a term accepted by the trusted kernel. Atomic action: construct a proof-term search/evaluation rule. | Elaborator/tactic ecosystem plus kernel checking; all must preserve the theorem and kernel acceptance. | Lean/mathlib theorem files; elaboration, tactic search, kernel checking, term size, memory, diagnostic behavior. | Deep. |
| GNU ld / ELF | Map identical inputs into loader-equivalent output under a fixed link contract. Atomic action: section-placement selection. | Linker-script language and native linker choices. | Real object-file/link workloads; linker time/memory, output size, relocation/layout, loader-visible behavior. | Structural drop. |
| CBOR | Emit the unique deterministic representation of the same data item. Atomic action: canonical field ordering/shortest form. | RFC deterministic encoder/decoder rules. | Signed/verified CBOR documents; encode/decode/verification and bytes. | Structural drop. |
| FlatBuffers | Build a buffer accepted by the native verifier and read to the same table. Atomic action: builder layout emission. | Current builder, generated accessors, and verifier. | Public schema-generated buffers; construction, verification, reading, bytes, allocation. | Structural drop. |
