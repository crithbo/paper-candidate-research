# UNIQUE_OPPORTUNITY_FAMILIES

The unit is the opportunity family, not a tool/API occurrence. Six cards are distinct from each other and from the local Source01–07 S1 identities by fixed object/guarantee: LLVM optimized-DWARF call-site reconstruction; Go foreign pointer retention; Wasm GC rec-group validation; robust-futex exit publication; RISC-V CAS lowering; and RISC-V byte/halfword atomic lowering.

| Family | Exact distinction | Status |
|---|---|---|
| C01 LLVM DWARF call-site | Debugger-visible call parameter reconstruction for fixed optimized native code | briefed |
| C02 Go cgo Pinner | Go GC pin lifetime during foreign retention | raw only |
| C03 Wasm GC rec group | Recursive-type validation/canonicalization | dropped in precommitted depth |
| C04 Linux robust futex | Owner-death recovery publication | raw only |
| C05 RISC-V Zacas | CAS versus LR/SC lowering | dropped in precommitted depth |
| C06 RISC-V Zabha | subword atomic lowering | raw only |
