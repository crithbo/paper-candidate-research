# Candidate-grade deep reviews

## D1 — RelProp relational reachability product/reward construction

**Frozen object and oracle.** The input is one PRISM-format MDP with the same initial-state labels, target labels, scheduler quantification, coefficients, comparison operator and epsilon; the output is the same RelProp Yes/No/Unknown relational-reachability result.  The stock oracle is current RelProp on Storm, not a different hyperlogic or a changed quantifier semantics.

**Current executable union.** Current first-party README documents the semantic flags `--numScheds`, `--numInit`, `--schedList`, `--targets`, `--coefficient`, `--comparisonOperator`, `--epsilon`, `--buechi`, `--checkModel`, and sample use of `--exact`; current source is a Python procedure on Storm's expected-reward facilities.  The primary CAV paper already gives a tractable product/reward construction for its specified fragment and states the hardness boundary.  Storm's single- and multi-objective solvers are part of the fair union.

**Minimal legal witness.** Two role-labeled target occurrences may be syntactically distinct yet refer to the same target/state role.  A construction can either retain two role-tuples or identify them and regenerate the coefficient/product references; both preserve the fixed relational query.  This is a legal representation divergence, not evidence of performance improvement.

**Subtraction and decision.** The only named improvement after subtraction was quotienting/folding equal product roles.  It is generic product-state minimization and is subsumed by the paper's direct relational construction plus ordinary symbolic quotienting; no target-specific exact/FPT/Pareto theorem was identified.  Therefore this is `STRUCTURAL_DROP__DIRECT_METHOD_AND_GENERIC_QUOTIENT_RESIDUAL`, not a conclusion about implementation readiness.

**Natural/full-cost route and falsifier (not executed).** CAV artifact PRISM/QVBS-style benchmarks; oracle equality is RelProp result plus exported model/query validity.  Cost ledger would include parse/product/reward-solve CPU/RSS/temp and model size.  A 72-hour Stage-A falsifier would be one duplicate-role benchmark whose quotient construction is either rejected by the frozen semantics or matches the current union with no non-generic guarantee.  Because the structural subtraction already fails, no Stage0 brief is warranted.

## D2 — omega-regular stochastic supermartingale certificate construction

**Frozen object and oracle.** The input is a fixed artifact JSON stochastic system and omega-regular condition; output is a verification/control result with an LDBSM certificate accepted under the artifact's stated semantics.  The oracle is the stock artifact checker/result path, not a changed controller policy or a compressed external certificate language.

**Current executable union.** The current official repository identifies verification/control modes, JSON inputs, the LDBSM certificate method, benchmark runner and report output.  It is source-backed that synthesis is native to the artifact; bounded review did not establish every internal option as a complete action catalog, so it does **not** support an absence claim.

**Minimal legal witness.** For a fixed polynomial degree and product-state basis, two coefficient-sharing bases can encode the same candidate supermartingale predicate.  Both are legal candidate representations pending the same synthesis/checking path.

**Subtraction and decision.** The proposed joint basis/certificate planner is an unconstrained reduction of generic constraint/certificate synthesis.  It lacks a target-specific state parameter, independent checker-side guarantee, and direct residual beyond the native synthesis kernel.  It is therefore `STRUCTURAL_DROP__GENERIC_CONSTRAINT_SYNTHESIS_KERNEL`, not a failure caused by absent experiments or results.

**Natural/full-cost route and falsifier (not executed).** The official artifact benchmark JSONs are the natural carrier; the full cost would include synthesis, checker/report, certificate bytes, CPU/RSS/temp.  A finite killer would reject the line if identical certificates can be generated by the existing synthesis kernel without the proposed target-specific restriction.  This structural condition is already decisive.
