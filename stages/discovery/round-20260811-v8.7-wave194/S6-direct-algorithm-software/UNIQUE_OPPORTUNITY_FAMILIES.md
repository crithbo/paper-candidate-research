# Unique opportunity families

For a fixed logical graph/object, an admissible action may jointly assign definitions/IDs, reference encodings and section/table layout, then regenerate every dependent reference. Same reader/verifier acceptance and semantic equality are mandatory.

The common minimal legal witness is two independent definitions whose IDs are swapped and every corresponding varint/coded-index/reference is regenerated. It demonstrates format legality only. It is not an action gap: a valid N2 must name a global writer constructor outside the complete current union and a nontrivial algorithmic/complexity/approximation guarantee. Frequency-only sorting, local emit patches, generic graph layout/ILP, external compression and changed format/reader are excluded.
