# RVV r6a independent preclaim fidelity review

Decision: `BOUNDED_CONTRACT_LOCAL_CORRECTION__NO_SCIENTIFIC_INFERENCE`.

The exact MIR stage supports only `-run-pass=greedy`; current/default/PBQP full-pipeline modes all exit nonzero and PBQP run-pass exits 1. Therefore a greedy-only comparison is not a fair current-vs-strong-baseline closure, and unsupported modes may not be silently excluded.

The controller declares r5d split-closure keys and a planned candidate, but does not execute or materialize the closure into candidate results; its full-cost receipt requires 15 candidate and 56 baseline metrics that do not exist. It is interface support only, not evidence that the r5d closure is implemented in the natural candidate path.

Bounded same-object route: freeze one correction that either establishes a native binding for each required baseline at the exact MIR stage or contracts the comparator set before execution with explicit same-function justification; then materialize and validate all r5d closure keys plus a shared cost tensor before any claim run. No revision/pivot, native replay, network, claim, state or Stage B action is authorized by this review.
