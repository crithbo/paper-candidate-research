## Exact-object audit

The same-object contract is adequate if all runs freeze repository URL and commit/ref closure; the complete reachable object IDs, types, canonical sizes and contents; Git tag/commit; repository hash algorithm; compression/format settings; input manifest; and host/resource budgets.

The output must be one ordinary non-thin, unfiltered, self-contained pack plus index. ## Strongest finite fair baseline

The fair deployment comparator is a finite family, not an impossible simultaneous union:

- current Git default pack-objects/repack;
- preregistered budget-matched window/depth/window-memory points;
- name-hash-version 1 and 2 where each is legal;
- path-walk and its ordinary second pass;
- reuse/no-reuse and delta-island variants only when identical initial state and exact output semantics permit them;
- Git's native family-aware write order;
- deterministic simple constructors under the same candidate-generation budget.

Path-walk and delta islands are incompatible, and name-hash version 2 has bitmap restrictions. “Union” therefore means beat every applicable, individually realizable configuration under the same information and budget; it does not mean combine incompatible switches into a fictional super-baseline.

The tiny exact solver is an offline ceiling only. Generic PPC/MinHash, Finesse, LoopDelta, and clustered delta graph methods are subtractors or adjacent references when their collection, encoding, access model, or deployment contract differs.
