# Current fork / CAR facet matrix

## Native action catalog (current-union correction)

| Surface | Native behavior | Role after revision |
|---|---|---|
| `Conversation.fork()` | copies conversation events, agent and agent state | existing baseline; not a candidate action |
| `LocalConversation.fork()` | constructs the fork with the same workspace reference | explicit counterexample to whole-environment isolation |
| `ConversationState` persistence | serializes public state/events and restores compatible agent/tools | supplies part of clone manifest only |
| `BaseWorkspace` | sandbox files/commands and pause/resume interface | must receive a branch-specific worktree/container reset contract |

The static certificate deliberately makes no repository-wide absence claim. It only maps these confirmed surfaces into copied, reset, shared-read-only or forbidden-writable categories.

## CAR separation

| Facet | CAR | PatchValue accepted residual |
|---|---|---|
| intervention time | historical step/action/observation/context/policy | post-prefix future compute allocation |
| treatment | counterfactual action manipulation/replay | absorbing stop vs registered fixed future call dose |
| principal target | causal responsibility / point of commitment | effect and lower-confidence frontier of extra future coding calls |
| state fidelity | generic agent replay assumptions | explicit native-fork plus whole environment SUTVA schema |
| evaluator | outcome under replay | sealed offline-only label with access firewall |
| permitted result | attribution | fixed-agent/model/decoder same-state measurement; optional downstream allocation only |

If the difference in this table cannot survive direct closing review, the static certificate must be rejected under the frozen failure sentinel.

## Seed-distance / de-naming test

Removing the labels “PatchValue” and “CAR” leaves two different propositions: (a) which prior agent action caused an outcome, versus (b) whether spending a fixed number of **future** complete calls from a frozen coding state has a positive lower-bounded effect under a sealed evaluation protocol. Changing (b) into model choice, restart, task difficulty prediction, remaining-time prediction, or unconstrained budget allocation violates the certificate.
