## Adversarial findings and disposition

1. **Startup profile is powerful.** It constructs linked collections in profile-rule order and appends default layout.  The certificate therefore fixes the supplied profile `P` and refuses to call a predecessor-derived new profile “same information.”  Otherwise profile manufacture would be an input change, not a layout comparison.
2. **R8 exposes a testing strategy wrapper.** It makes all legal writer actions embeddable but has no stock objective/solver.  Treating it as a current oracle would be circular, so it is recorded as native realization rather than an absorbed policy.
3. **VCDIFF is underspecified as an encoder.** The theorem restricts itself to a full deterministic bounded source-only contract and carries all delayed/coder state.  It does not infer xdelta3 or mobile-patcher performance.
4. **DEX offset fields can make the state large.** The `k` parameter includes unresolved ID/class-data offsets.  There is no claim of a universal small state or practical speedup.
5. **The two natural carriers are not results.** They are only finite Stage-A acquisition targets and fail closed if artifacts are not ordinary single DEX under the frozen provenance contract.
