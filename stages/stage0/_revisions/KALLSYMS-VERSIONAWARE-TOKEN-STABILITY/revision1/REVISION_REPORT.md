## Single atomic proposition

**ONLINE_FIXED_PREDECESSOR / native-link proposition.**  For a pinned predecessor kernel image `P`, a pinned target tag/config/toolchain, and each target map produced by the native kallsyms relink schedule, there is a finite grammar of stock-reader-compatible kallsyms representations.  Within its link-fixed-point-preserving subgrammar, `LKF` computes an exact Pareto frontier (or emits a certified width-cap failure) for predecessor patch cost and native representation cost; its frontier contains a legal action not expressible by the frozen greedy constructor or a finite predecessor-token-stability heuristic grid.

`P` is an online, already-installed predecessor.  It is an input to the constructor and to every fair comparator; it is not a detached target-map encoder.  The target representation is regenerated by the candidate's kallsyms constructor during every native `dummy → relink → regenerate → final map cmp` pass.

**Falsifier.**  The proposition fails if (a) a candidate output cannot be emitted and decoded by the unmodified native reader, (b) its object layout is not link-fixed-point preserving, (c) the complete action catalog maps to the current greedy/stability-grid union, (d) a state merge changes a legal future action or exact declared cost, or (e) a certified frontier contains no union-nondominated target on the frozen natural chain.  Any (a)–(d) is the pre-registered scientific sentinel `BELOW_Q2_STOP__DETACHED_MAP_ENCODER_OR_GENERIC_DELTA_TUNING`; (e) is the Stage-A mechanism killer.

## Frozen same-object contract

The target is a fixed official Linux tag, architecture, `.config`, compiler and binutils tuple.  The predecessor is the immediately installed image made by the same frozen contract at the preceding official tag.  Observable semantics are the stock `kallsyms` address/name lookup, sequence/name lookup, System.map relation and normal boot contract.

Only the target constructor may select a different **native** `kallsyms_names` encoding and token-table/index assignment.  The native reader, its recursive expansion, marker cadence, offsets, sequence array, address relation, architecture, flags and final image format do not change.  In particular, `--all-symbols` and `--pc-relative` are frozen object dimensions, not actions to be tuned.  VCDIFF, other image deltas and a finite predecessor-stability grid receive the identical predecessor and target information, but remain comparators.

## Complete native grammar and link transition

For each native pass map `M`, `read_map`, filtering and address ordering produce the fixed logical symbols `(type,name,seq)`.  A legal representation `R(M)` is generated as follows.

1. Literal byte codes used in symbol strings have self productions.  An optional token code has a two-symbol right-hand side whose two expansions are already defined; hence the production dependency graph is acyclic and stock recursive `expand_symbol` terminates.
2. A production is applied only through the native left-to-right, non-overlapping replacement semantics used by `compress_symbols`.  The candidate may choose a legal production/order/slot assignment, but may not invent a different string grammar.
3. The stock writer emits the ULEB name length plus compressed name bytes, 256-symbol markers, token table and index, fixed-width offsets and three-byte name sequence array.  It must emit the same logical symbols and preserve all reader predicates.  Empty unused entries remain empty; no reader extension or extra side table is admitted.
4. The **link-neutral subgrammar** `R0(M)` contains only actions whose assembled `kallsyms.o` has the stock section sizes, alignment, relocation layout and symbol layout at that pass; bytes in the emitted data payload may differ.  Therefore the native linker sees the same relocation/layout problem.  On the frozen no-layout-threshold fixture and on any Stage-A target accepted into `R0`, the native map transition is identity on the logical map:

   `Phi_M(R) = M` after the script's regenerate/relink cycle.

   The candidate nevertheless participates in the real script: dummy kallsyms, relink, regeneration, optional extra pass and final `cmp -s System.map kallsyms_sysmap`.  An action is rejected if any pass changes the prescribed ELF-layout signature or if the final map comparison fails.  Thus the construction is not a frozen-map/post-link encoder.

`R0` is deliberately stricter than all legal representations.  It gives a finite, auditable fixed-point route.  If its action frontier is empty or loses to the union on natural chains, the project stops rather than relaxing the object or guarantee.

## LKF: link-fixed Kallsyms frontier

`LKF` constructs a factor graph from native production alternatives, code slots, overlap occurrences, recursive dependencies, per-symbol ULEB/marker residues and the declared source-only patch transducer state.  It uses a fixed nice path decomposition of this **complete** graph.  A frontier state at bag `i` is:

`(i, active-productions, slot-ownership, open-replacement-runs, name/ULEB/marker residue, table-index residue, E_B source-window state, exact cost vector)`.

The link-layout signature is fixed to the stock value by `R0`; it is a legality predicate, not an omitted cost.  Two states merge only when these fields and every boundary production are identical.  Then every legal suffix has exactly the same native decoded symbols, emitted bytes, `E_B` transition and full-cost vector.  This is the future-action/full-cost sufficiency invariant.

For a decomposition of width `p`, bounded patch window `B`, and a fixed native alphabet of at most 256 codes, LKF is exact in its declared subgrammar with time `O(N · f(p,B,256))` and polynomial state verification; `f` is exponential in the displayed boundary, and no polynomial or general-instance FPT claim is made.  If a required bag exceeds the frozen cap, LKF returns `WIDTH_CAP_EXCEEDED` plus its complete boundary transcript — not a beam result and not a positive outcome.  A retained state has a checkable predecessor/action chain; a pruned state has an exact componentwise dominance certificate.  Generic ILP/CP may audit small instances only and is not the method.

This is non-product because a production slot changes both the target's recursively decoded token grammar and the predecessor patch transducer state while the link-neutral legality predicate couples all emitted native arrays.  A scalar token-profit reweighting or finite parameter grid cannot represent that state relation.

## Static native two-version action-divergence witness

The following legal data-bearing fixture is sufficient to distinguish actions; it is not a performance result.  The predecessor assigns slots `254 -> "ab"` and `255 -> "xy"`.  The target map includes ordinary text symbols whose names contain two separated `ab` runs in each of `tabab0`, `tabab1`, and three separated `xy` runs across `txyxy0`, `txy1`; all other digram occurrences are limited below these counts.  The current greedy two-byte profit order therefore assigns `255 -> ab` before `254 -> xy`.  LKF instead assigns `255 -> xy`, then `254 -> ab`, preserving predecessor slot identity.

Both plans use the same two productions, the same number of substitutions, equal-length token expansions, identical ULEB lengths, marker positions, offsets, index widths, assembly directives, relocations and ELF section layout.  They are therefore both legal members of `R0`, and their native relink transition is the same fixed point.  They differ in the actual `kallsyms_names` code bytes and token-table payload, so this is not a rename of the greedy output.

For the frozen source-only transducer `E_B`, commands are canonical `COPY(offset,length)` when the longest source match is at least three bytes (ties: lowest source offset), otherwise `ADD(bytes)`; command tag and each ULEB field cost one byte.  On the displayed data-bearing regions, predecessor-compatible ordering has one source copy of the unchanged slot/table run plus one three-byte add: `3 + 5 = 8` command bytes.  The greedy swapped ordering requires two three-byte copies and two code-byte adds before the same final add: `3 + 3 + 4 + 5 = 15` command bytes.  Common native sections are copied identically in both traces, so the strict local difference survives in the full deterministic ledger.  Stage A must regenerate this transcript from the actual assembled image and reject the witness if the full-image encoder or fixed-point trace disagrees; no full-image saving is claimed now.

## Strong union, full cost, and finite Stage-A falsifier

The pre-registered fair union is: full current pinned Linux kallsyms/link fixed point; stock image plus pinned VCDIFF; stock image plus a second strong binary delta; a finite predecessor-token-stability heuristic grid; and a tiny exact oracle only.  Every method receives the same predecessor, target map, tag/config/toolchain, map passes and output contract.

The Stage-A pre-claim fidelity gate uses 20 adjacent official tags across two frozen configuration families.  It first verifies reader round trips, `System.map` equality, ELF-layout signature, fixed-point convergence and the static fixture.  Its full ledger contains generated image plus patch bytes, native link/constructor CPU, peak RSS, optimizer/predecessor preprocessing, token/table bytes, boot/name lookup checks, failures and fallback.  The atomic killer is any of: no action in `R0`; any reader/map/layout/fixed-point failure; an action frontier coverage below 10%; or no p50/p90 Pareto point outside the entire union after full costs.  This is a finite CPU/build route; no unavailable hardware is required.

## Decision rationale and routing

The revision closes the single required *research-design* gate: it names one online semantics, a complete native subgrammar and fixed-point transition, a sufficient state, an honest bounded-width exact guarantee, and a native action-divergence witness.  It does not assert the gate has experimentally succeeded.  Route only to the independent closing reviewer; do not authorize Stage A/B.
