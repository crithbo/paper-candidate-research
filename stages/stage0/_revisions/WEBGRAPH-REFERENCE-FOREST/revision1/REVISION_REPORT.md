## Complete current pipeline audit

The released first-party source establishes the following full action:

1. Each list is encoded as a root and against every nonempty legal predecessor within the window using the native compressor and estimator.
2. The locally minimum-bit predecessor for each node forms the maximum-weight best-parent forest.
3. `update_references_for_max_length` runs a dynamic program over that forest to enforce the chain-depth bound.
4. `find_additional_references_greedily` scans nodes in increasing order, considers all legal predecessor deltas, filters them using current backward chain length plus the precomputed forward-chain length, and selects the minimum-bit feasible reference.
5. `write_and_clear_current_chunk` recompresses the chosen references into the native stream and records native offsets.

The source therefore absorbs the generic contribution “global bounded reference forest,” the original sibling witness, a best-parent-pruning-only attack, and an action that only changes flags or edge weights. Any surviving contribution must beat step 4's final forest, not step 3's intermediate forest.

## Revision attempt and why it fails

### Rejected sibling witness

Discovery's edges `1→0` and `2→0` are siblings. With a path-depth bound, both can coexist. They do not exhibit either competition or an action unavailable to `BvCompZ`.

### Rejected abstract chain/star pattern

PRIMARY and confirmation identify an abstract pattern with edges `1→0`, `2→1`, and alternative `2→0`, where hand-written savings satisfy:

`w(2→1) > w(2→0) > 0` and `w(1→0) + w(2→0) > w(2→1)`.

For maximum depth one, this can make the best-parent chain lose to a complete-edge star. Static inspection also shows why the refill can remain order-dependent. However, this is only an abstract weighted-DAG counterexample. The package has no actual sorted lists, exact native settings, measured or analytically derived `reference_costs`, final emitted forest, graph stream, or offsets establishing that the inequalities occur under the frozen encoder. Treating the chosen weights as native facts would be author injection.

### Rejected nested-list family

A tempting proposed family is `L0=A`, `L1=A∪{x}`, `L2=A∪{x,y}`. It is realizable as sorted successor lists and plausibly creates the desired relative similarity. It still does not close the gate: BVGraph cost includes reference delta, copy blocks, intervals, residuals and code-dependent headers. Without the pinned estimator output or a complete analytical derivation, neither the best-parent relation nor the strict final-objective inequality follows. The family is a Stage A search seed, not a Stage 0 action-divergence certificate.

### Formal route that survives alone

For fixed window `W` and depth `D`, a left-to-right frontier dynamic program could maintain parent/depth information for the most recent `W` lists, choose root or one legal predecessor for the next list, and minimize additive native edge cost. This gives a plausible exact parameterized route with state count exponential in a function of `W` and `D`, rather than unrestricted whole-graph enumeration.

That statement is not sufficient by itself. Without a native-realizable action missed by the full current pipeline, it is a generic optimizer for an action space whose same-object headroom has not been defined. Conversely, a native counterexample without a nontrivial property would be a heuristic audit. The atomic gate requires both to be linked.
